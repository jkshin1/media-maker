# 오프닝 오디오 소스 및 검증

이번 오프닝 전용 자료입니다. 기존 18초 샘플과 241초 전체 제작의 오디오를 교체하지 않습니다.

## 재실행

Python 3와 `ffmpeg`가 PATH에 설치되어 있어야 합니다. 추가 Python 패키지나 API 키는 필요하지 않습니다.

프로젝트 루트에서 다음 명령으로 이미 가져온 음원과 원본 컷을 다시 믹스합니다.

```sh
python3 opening/audio.py
```

`opening/` 디렉터리만 별도로 옮긴 경우에는 해당 폴더에서 실행합니다.

```sh
python3 audio.py --output ./output
```

출력은 `audio.wav`, `narration.wav`, `narration-raw.wav`, `audio-validation.json`입니다. HTML 미리보기용 `narration/mix.wav`도 같은 최종 PCM으로 갱신됩니다. `audio.py`는 원격 음성을 생성하거나 다른 서비스로 음원을 전송하지 않습니다.

원본의 문장별 PCM 컷을 다시 만들려면 다음 명령을 실행합니다. 저장된 로컬 Whisper 전사와 파형 경계 검증 자료를 사용하며, 재전사는 하지 않습니다.

```sh
python3 opening/narration/align.py
```

## 내용 및 컷 검증

설치된 로컬 OpenAI Whisper `small`로 전체 마스터를 전사했습니다. 9개 문장의 내용과 마지막 문장을 확인하고 8개 경계를 문장·단어 타임스탬프와 파형 휴지 구간으로 검증했습니다. 6–7번 문장 사이에서는 Whisper가 다음 문장의 첫 단어 시작을 앞 문장의 끝에 붙이는 근사 타임스탬프를 반환했습니다. 해당 컷 지점에서 시작하는 별도 원본 구간을 다시 전사해 7번 문장의 첫 단어와 문장 전체가 보존됨을 확인했습니다. 자료는 `transcription/`에 있습니다.

ASR에는 ‘현업의/현업에’, ‘견화가/변화가’, ‘아이전트/에이전트’처럼 철자 인식 오차가 남아 있습니다. 전사는 문장 전체의 포함 여부와 경계 검증 자료이며, 글자 단위로 완벽한 ASR을 보장하는 근거로 사용하지 않습니다. 승인된 생성 프롬프트는 원문 그대로 보존했습니다.

## BGM 및 믹스

`bgm/music.mp3`는 기존 프로젝트에 도입되어 라이선스를 확인한 Andrew Ev의 **Mountains**입니다. 원본의 차분한 도입 0–46초 구간을 사용하며, 낮은 볼륨과 나레이션에 반응하는 sidechain ducking, 부드러운 입·출력 페이드를 적용했습니다.

- 원본 및 사용 기록: `bgm/provenance.json`
- 당시 확보한 라이선스 문서: `bgm/license.html`
- 출처: https://mixkit.co/free-stock-music/tag/corporate/?page=2
- 라이선스: https://mixkit.co/license/modal/musicFree/

라이선스는 나레이션을 포함한 영상 결합 사용을 위한 것입니다. 음원 단독 재배포·소유권 주장·권리 관리 서비스 등록은 허용되지 않습니다.

최종 믹스는 정확히 46.000초, 48000 Hz stereo PCM16입니다. 현재 렌더의 통합 음량은 −17.21 LUFS, true peak는 −4.92 dBTP이며, FFmpeg 전체 오디오 디코딩을 통과했습니다. 최종 MP4의 AAC 인코딩·영상 복사·영상 재생 검수는 별도의 영상 검증 보고서에서 확인해야 합니다.
