# R&D 공정 AI Fast Track 영상 공통 제작 규칙

## 1. 문서 목적

본 문서는 R&D 공정 AI Fast Track 성과공유회 영상 제작을 위한 공통 디자인 및 구현 규칙이다.

최종 영상은 오프닝, 12개 AI Agent 과제 영상, 우수 과제 소개 전환부를 하나로 연결한 MP4 파일로 제작한다. 각 과제의 기존 시안과 실제 기능·성과를 존중하며, 공통 규칙은 영상 전체의 일관성을 확보하는 데 사용한다.

## 2. 최우선 제작 원칙

1. **기존 과제 시안을 임의로 재해석하거나 변경하지 않는다.** 각 과제별 시안은 해당 과제의 화면·기능·스토리 표현에 대한 기준 자료다.
2. **실제 자료에 없는 기능, 수치, 절감 효과, 분석 결과를 만들어내지 않는다.**
3. **공통 디자인은 유지하되 과제별 화면 구성과 연출은 차별화한다.** 12개 과제를 똑같은 템플릿처럼 보이게 만들지 않는다.
4. **텍스트는 후편집으로 정확하게 삽입한다.** 이미지·영상 생성 모델이 글자나 숫자를 그리도록 하지 않는다.
5. **최종 결과물은 재생 가능한 MP4 파일로 출력한다.** 제작 과정에서 HTML, SVG, Python, FFmpeg 등 적합한 구현 도구를 사용할 수 있으나, 최종 납품물은 MP4여야 한다.
6. 입력 자료가 부족하거나 과제 정보가 불명확하면 내용을 추측하지 말고 사용자에게 확인한다.

## 3. 기본 영상 사양

- 화면 비율: 16:9
- 기본 해상도: 1920 × 1080 (Full HD) 이상
- 출력 형식: MP4
- 권장 프레임레이트: 30 fps
- 권장 코덱: H.264 영상 / AAC 오디오
- 전체 길이: 기존 구성안 기준 약 130초. 실제 과제별 영상 길이에 따라 조정할 수 있다.
- 안전 여백: 타이틀과 자막은 화면 가장자리에서 충분히 떨어뜨려 배치한다.
- 화면 내 텍스트는 대형 화면에서도 읽을 수 있는 크기와 대비를 확보한다.

## 4. 공통 색상 팔레트

| 역할 | 색상 | HEX | 사용 원칙 |
|---|---|---|---|
| 메인 배경 | Deep Black | `#080808` | 기본 배경 |
| 보조 배경 | Dark Gray | `#1A1A1F` | 패널·구분 영역 |
| 메인 포인트 | Gold | `#D4AF7C` | 타이틀·핵심 강조 |
| 밝은 강조 | Warm Gold | `#F5D6A6` | 빛·핵심 문구 |
| 빛 효과 | Amber | `#FFB347` | 광원·전환 효과 |
| 본문 | Warm White | `#F2EEE7` | 설명 문구 |

골드와 앰버는 포인트로 사용한다. 모든 요소를 금색으로 채우지 않으며, 밝은 효과가 화면의 가독성을 해치지 않도록 한다. 과도한 파란색 네온은 공통 스타일로 사용하지 않는다. 단, 과제 화면의 실제 UI나 원본 시안에 다른 색상이 필요하면 원본의 의미와 기능을 우선한다.

## 5. 전체 분위기와 시각 언어

- 프리미엄, 정교함, 신뢰감, 미래지향적인 반도체 R&D 분위기
- 실제 반도체 웨이퍼, 정밀 장비, 클린룸, 연구개발 현장, 데이터 시각화 등 과제와 관련 있는 소재 활용
- 검정 배경과 절제된 골드 조명으로 깊이감 형성
- 현실적인 질감과 시네마틱한 조명 사용
- 과도한 SF, 로봇, 불필요한 홀로그램, 무관한 우주·게임풍 이미지는 지양
- 장식은 메시지를 보조하는 범위에서만 사용하고, 핵심 정보보다 튀지 않게 한다.

## 6. 타이포그래피

- 메인 타이틀: 고급스러운 세리프체 또는 명료한 산세리프체 중 시안과 어울리는 스타일 사용
- 본문·설명: 가독성 높은 산세리프체 사용
- 메인 타이틀, 과제 번호, 과제명, 보조 설명의 위계를 명확히 한다.
- 타이틀과 본문을 과도하게 많이 넣지 않는다.
- 문구는 승인된 원문을 그대로 사용하며 임의로 고쳐 쓰지 않는다.
- 한글 자소 분리, 오탈자, 숫자 왜곡, 영문 대소문자 오류가 없는지 출력 전에 확인한다.
- 자막은 배경과 충분한 명도 대비를 확보한다.

## 7. 공통 그래픽 요소

필요에 따라 아래 요소를 사용한다.

- 반도체 웨이퍼의 원형 패턴
- 얇은 골드 라인과 정교한 기하학적 프레임
- 빛의 입자와 절제된 광원
- 데이터 흐름을 상징하는 선과 점
- 과제 번호를 보여주는 간결한 카드형 프레임
- 실제 과제 화면을 담는 직사각형 패널

이 요소들을 모든 장면에 전부 넣지 않는다. 장면의 목적에 맞는 요소만 선택한다. 과제별 시안에 실제 UI나 이미지가 있다면 해당 시안을 우선한다.

## 8. 카메라와 애니메이션

권장하는 움직임:
- 느린 줌인 또는 줌아웃
- 부드러운 좌우 패닝
- 깊이감을 주는 전경·배경의 미세한 패럴랙스
- 타이틀의 절제된 페이드인·페이드아웃
- 빛이 한 방향으로 흐르며 다음 장면을 연결하는 전환

피해야 할 움직임:
- 잦은 흔들림과 과도한 회전
- 의미 없는 빠른 확대·축소
- 과도한 플래시, 글리치, 파티클 폭발
- 모든 컷에 동일한 전환 효과를 반복하는 것

움직임은 장면의 메시지를 돕는 데 사용하고, 텍스트가 읽히는 시간을 충분히 확보한다.

## 9. 장면 전환

- 오프닝에서 첫 번째 과제로 넘어갈 때는 빛의 흐름, 프레임 이동 또는 부드러운 페이드로 연결한다.
- 과제 사이의 전환은 짧고 명료하게 구성한다.
- 각 과제 영상의 시작·끝 프레임과 충돌하지 않도록 실제 영상 길이와 화면을 확인한다.
- 과제 원본 영상의 내용을 임의로 잘라내거나 덮어쓰지 않는다. 편집이 필요하면 별도 사본을 만들고 사용자의 승인 범위 안에서 진행한다.
- 전환 효과가 과제 본편의 핵심 정보나 제목을 가리지 않도록 한다.

## 10. 자막·나레이션·음향

- 나레이션 문구는 승인된 문장을 사용한다.
- 나레이션은 장면의 길이에 맞춰 자연스럽게 배치하고, 과도하게 빠르게 읽지 않는다.
- 배경음악은 시네마틱하고 절제된 분위기로 하며 나레이션을 가리지 않는다.
- 전환 시 효과음은 필요할 때만 낮은 강도로 사용한다.
- 저작권이 확인되지 않은 음악·효과음을 임의로 사용하지 않는다.
- 무음 버전이 필요할 경우에도 화면만으로 핵심 메시지를 이해할 수 있게 구성한다.

## 11. 과제별 차별화 규칙

공통 색감과 타이포그래피를 유지하면서 과제별 핵심 소재에 따라 시각적 구성을 바꾼다.

- 웨이퍼 분석 과제: 웨이퍼 또는 실제 분석 결과 중심
- 장비·공정 과제: 실제 장비와 공정 흐름 중심
- 검색·분석 과제: 실제 화면, 결과 표, 관련 시각화 중심
- 자동화 과제: 입력 → 처리 → 결과의 흐름 중심
- 각 항목은 예시일 뿐이며 실제 과제 자료에 맞게 선택한다.

위 예시는 과제의 기능을 추측하기 위한 근거가 아니다. 실제 자료에 존재하는 기능만 표현한다. 과제별 시안에 포함된 화면·기능을 새로 디자인하거나 잘못된 그래프로 대체하지 않는다.

## 12. 텍스트·수치·UI 정확성

- AI 이미지 생성 과정에서 만들어진 가짜 UI, 가짜 차트, 임의 숫자를 실제 기능 화면으로 사용하지 않는다.
- 실제 UI가 필요한 경우 제공된 스크린샷이나 승인된 원본을 사용한다.
- 성과 수치와 시간 절감 효과는 원본 자료에 명시된 값만 사용한다.
- 불확실한 정보는 생략하거나 사용자에게 확인한다.
- 화면 속 데이터가 장식용이라면 실제 데이터로 오해되지 않게 사용을 최소화한다.

## 13. 제작·출력 규칙

- 소스 코드와 입력 자료는 수정 가능한 상태로 정리한다.
- 최종 MP4와 함께 필요한 경우 실행 방법 및 사용한 리소스 목록을 제공한다.
- 인코딩 후 전체 영상을 처음부터 끝까지 재생해 화면 잘림, 오탈자, 검은 프레임, 음성·영상 싱크, 전환 오류를 확인한다.
- 원본 과제 영상과 최종 통합 영상의 길이·순서를 점검한다.
- 최종본은 1920 × 1080, 16:9 MP4를 기본으로 한다.

## 14. 전체 구성 기준

현재 기획안의 기본 흐름은 다음과 같다.

1. 오프닝: R&D 공정과 AI Fast Track 소개
2. 12개 AI Agent 과제 소개
3. 각 과제의 기존 시안 및 실제 과제 영상 삽입
4. 우수 과제 2건 소개로 전환
5. 실제 발표 화면으로 자연스럽게 연결

기존 시안에 표시된 시간은 초기 구성 예시다. 실제 과제 영상의 길이에 맞춰 최종 타임라인을 조정한다. 과제별 영상 시간을 확인하기 전에 전체 길이를 확정하지 않는다.

## 15. 제작 완료 전 체크리스트

- [ ] 16:9 화면 비율과 Full HD 이상 해상도
- [ ] 블랙·골드·앰버 공통 분위기 유지
- [ ] 과제별 화면 구도와 연출 차별화
- [ ] 기존 과제 시안과 실제 기능 보존
- [ ] 임의의 기능·수치·성과 추가 없음
- [ ] 한글·영문·숫자 오탈자 없음
- [ ] 자막 가독성과 안전 여백 확보
- [ ] 나레이션·음악·영상 싱크 확인
- [ ] 모든 과제 영상의 순서와 길이 확인
- [ ] 최종 MP4 전체 재생 검수 완료
