> 화면 비율: 16:9  
> 중요: 기존 시안의 5컷 구성과 기능 흐름을 유지한다. 확인되지 않은 기능이나 성과 수치는 임의로 추가하지 않는다.

## 1. 제작 목표

여러 시스템을 오가며 확인하던 공정 업무를 Cubic공정Lab 전용 포털 하나로 통합하고, Lot 조회, 장비 Status 조회, TEM 쿼터 예약, Daily/Weekly Report 자동 생성 등 주요 기능을 한곳에서 제공하는 흐름을 보여준다. 주말 근무자 메일 발신 기능은 시안에 표시된 기능 범위 안에서 표현한다.

기존 시안의 5컷 구성과 핵심 메시지를 유지한다. 각 컷 상단에는 장면 제목, 하단에는 나레이션을 배치한다. 나레이션은 분산된 업무 환경에서 시작해 통합 포털, 주요 기능, 간편해진 업무 환경, 기대 효과로 이어지도록 한다.

**나레이션**
> 여러 시스템을 오가며 확인하던 업무.

**화면 구성**

- 연구원이 시스템을 오가며 정보를 확인하는 기존 업무 환경을 표현한다.
- 실제 시스템 로고나 화면이 제공되지 않은 경우, 시스템명을 정확히 표시한 중립적인 화면 요소로 대체한다.
- 확인되지 않은 추가 시스템을 임의로 넣지 않는다.

**카메라·모션**
- 여러 시스템 화면 사이를 천천히 트래킹한다.

**화면 구성**
- Cubic공정Lab 포털 홈 화면을 중심으로 구성한다.
- Lot 조회, 장비 Status, TEM 예약, Daily/Weekly Report, 주말 근무자 메일 발신 기능이 포털 메뉴로 보인다.

- 모든 기능이 하나의 포털에서 접근 가능하다는 점을 보여주되, 시안에 없는 기능을 추가하지 않는다.

**카메라·모션**
- 포털 화면으로 부드럽게 푸시인한다.
- 주요 메뉴 타일이 순서대로 활성화된다.
- 화면 전환을 통해 CUT 3의 주요 기능 화면으로 이어진다.

**상단 제목:** `하나의 포털로 통합`

### CUT 3 — 주요 기능 제공

**나레이션**
> 조회부터 예약, 보고서 생성까지.

**화면 구성**
- 다음 기능을 기존 시안에 나온 순서와 스타일에 맞춰 보여준다.
  1. Lot 조회
  2. 장비 Status 조회
  3. TEM 쿼터 예약
  4. Daily/Weekly Report 자동 생성
  5. 주말 근무자 메일 발신 기능
- 각 기능은 별도 카드 또는 패널로 표현한다.
- Lot 상태, 장비 상태, 예약 시간, 보고서 그래프 등 구체적인 값은 승인된 원본 자료에서 확인되는 경우에만 사용한다.
- 시안의 예시 수치를 실제 운영 데이터처럼 임의로 재사용하지 않는다.

**카메라·모션**
- 기능 카드가 차례로 나타나고 각 카드의 핵심 UI가 짧게 애니메이션된다.
- Lot 조회 표는 행이 나타나는 모션, 장비 Status는 상태 배지 강조, TEM 예약은 예약 슬롯 강조, 보고서는 그래프와 표가 구성되는 모션을 사용한다.
- 주말 근무자 메일 발신 기능은 해당 기능이 제공된다는 점을 보여주며, 자동 발송 조건이나 예약 규칙은 임의로 만들지 않는다.

**상단 제목:** `주요 기능 제공`

### CUT 4 — 간편해진 업무 환경 (After)

**나레이션**
> 필요한 기능을 한곳에서 편리하게.

**화면 구성**
- Cubic공정Lab 포털에서 주요 정보를 한눈에 확인하는 화면을 보여준다.
- Lot 조회, 장비 Status, TEM 예약, Daily/Weekly Report 및 최근 보고서 등 실제 시안에 있는 포털 요소를 활용한다.
- 여러 시스템을 오가던 기존 환경과 달리 하나의 포털에서 업무를 이어가는 점을 시각적으로 강조한다.
- 시안의 예시 지표는 원본 자료에서 검증된 경우에만 사용한다.

**카메라·모션**
- 포털 화면을 정면에서 보여준 뒤 대시보드 내 주요 영역으로 부드럽게 이동한다.
- 좌측 메뉴와 콘텐츠 영역이 자연스럽게 반응한다.
- 그래프와 최근 보고서 목록은 미세한 UI 모션으로 살아 있는 화면처럼 표현한다.

**상단 제목:** `간편해진 업무 환경 (After)`

### CUT 5 — 기대 효과

**나레이션**
> 업무 시간을 90% 이상 단축합니다.

**화면 구성**
- 기존 시안의 핵심 효과인 업무 시간 단축을 중심으로 마무리한다.
- `업무 시간 90% 이상 단축` 수치는 사용자가 제공한 시안에 표시된 내용이다. 최종 영상에 넣기 전에 승인된 원본 자료와 정확히 일치하는지 확인한다.
- 수치가 확인되지 않으면 숫자를 제거하고 업무 효율 향상 메시지만 사용한다.
- 공정 장비 또는 웨이퍼 이미지를 배경에 두고 골드 포인트로 핵심 메시지를 강조한다.

**카메라·모션**
- 업무 시간 아이콘과 핵심 성과 문구가 순차적으로 등장한다.
- 배경 장비와 웨이퍼의 조명이 미세하게 움직인다.
- 마지막 문구를 읽을 수 있도록 잠시 유지한 뒤 다음 과제로 자연스럽게 연결한다.

**상단 제목:** `기대 효과`
