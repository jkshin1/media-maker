# 필요한 지식을 찾아, 업무에 활용하다
## 서머리 메시지 영상 제작 MD

> 목적: 확정된 단일 장면 시안을 기준으로 약 6–8초 길이의 시네마틱 모션 영상을 제작한다.  
> 중요: 화면에 `SUMMARY 1`, `SUMMARY 2`, `SUMMARY 3` 등 서머리 번호나 라벨을 표시하지 않는다.

---

## 1. 영상 콘셉트

**메인 문구**
- 1행: `필요한 지식을 찾아`
- 2행: `업무에 활용하다`

**보조 문구**
- 1행: `흩어진 정보 속에서 필요한 지식을 찾고,`
- 2행: `관련 데이터와 연결해 더 나은 업무 판단을 지원합니다.`

이 장면은 공정 지식, 기술 문서, 과거 평가 사례, 공정 데이터처럼 여러 곳에 흩어진 정보를 찾아 연결하고 실제 업무 판단에 활용하는 흐름을 전달한다. 개별 과제의 기능을 하나씩 나열하지 않고, 지식 탐색과 활용이라는 공통 가치를 강조한다.

## 2. 공통 디자인 규칙

- 화면 비율: 16:9 가로형
- 권장 해상도: 1920 × 1080
- 권장 프레임레이트: 30 fps
- 시각 스타일: 검정·차콜 배경, 골드·앰버 포인트, 프리미엄 반도체 R&D 분위기
- 기본 색상:
  - Black: `#080808`
  - Charcoal: `#1A1A1F`
  - Gold: `#D4AF7C`
  - Light Gold: `#F5D6A6`
  - Amber: `#FFB347`
  - Cream: `#F2EEE7`
- 확정 시안의 중앙 웨이퍼, 좌우 정보 패널, 중앙 문구, 골드 데이터 스트림 구도를 유지한다.
- `SUMMARY 1`, `SUMMARY 2`, `SUMMARY 3`, `SUMMARY 4` 등의 번호나 영문 라벨을 추가하지 않는다.
- 과제명, 담당자명, 과제 번호를 넣지 않는다. 이 영상은 개별 과제 타이틀이 아니라 서머리의 종합 메시지 장면이다.
- 문구는 정확한 한국어 텍스트 레이어로 구현한다. 이미지 안에 생성된 글자를 그대로 사용해 오탈자가 노출되지 않도록 한다.
- 실제 기능으로 확인되지 않은 수치나 기능을 새로 추가하지 않는다.

## 3. 길이 및 타임라인

총 길이: 약 6–8초. 단일 장면을 유지하되 카메라·조명·정보 패널·문서·텍스트가 실제로 움직이도록 제작한다.

### 0.0–1.5초 — 흩어진 자료가 드러남
- 어두운 R&D 공간에서 시작한다.
- 좌우 패널에 공정 지식, 기술 문서, 과거 평가 사례, 공정 데이터가 차례로 드러난다.
- 패널은 서로 다른 깊이에 배치해 입체감을 형성한다.
- 문서 카드와 작은 정보 아이콘이 공간에 떠 있으며, 천천히 움직인다.
- 카메라는 중앙 웨이퍼를 향해 천천히 전진한다.

### 1.5–3.0초 — 필요한 정보 탐색
- 좌우의 문서 카드와 데이터 패널 일부가 중앙을 향해 움직인다.
- 골드 데이터 스트림이 여러 자료를 연결하며 중앙과 웨이퍼 방향으로 흐른다.
- 정보가 단순히 한꺼번에 빨려 들어가는 연출보다, 관련 자료가 선택되어 연결되는 느낌을 준다.
- 파란색 아이콘은 시안에 있는 정도로만 절제해 사용하고, 전체 팔레트는 검정·골드 중심으로 유지한다.

### 3.0–4.5초 — 메인 문구 등장
- 중앙 문구를 두 단계로 표시한다.
  1. `필요한 지식을 찾아`
  2. `업무에 활용하다`
- 첫 번째 줄이 부드럽게 나타난 뒤, 두 번째 줄이 골드 강조와 함께 이어서 등장한다.
- 문구는 중앙 정렬을 유지하고 주변 패널과 웨이퍼를 과도하게 가리지 않는다.

### 4.5–6.5초 — 보조 문구와 정보 연결 강조
- 보조 문구를 두 줄로 순차적으로 표시한다.
  - `흩어진 정보 속에서 필요한 지식을 찾고,`
  - `관련 데이터와 연결해 더 나은 업무 판단을 지원합니다.`
- 골드 연결선이 문서 패널과 공정 데이터 패널 사이를 지나며 관련 정보가 연결되는 모습을 보여준다.
- 웨이퍼 가장자리의 골드 링 조명이 한 차례 흐르듯 이동한다.
- 카메라는 아주 천천히 전진해 화면에 깊이감을 더한다.

### 6.5–8.0초 — 메시지 유지 및 자연스러운 전환
- 모든 문구를 읽을 수 있도록 짧게 유지한다.
- 정보 패널, 문서 카드, 데이터 스트림과 조명은 미세하게 계속 움직인다.
- 다음 영상으로 연결할 경우 골드 데이터 스트림이 화면 가장자리로 흐르며 자연스럽게 전환한다.
- 별도 엔딩 크레딧이나 서머리 번호를 추가하지 않는다.

## 4. 모션 구현 지침

단순히 확정 시안 이미지를 확대하거나 축소하는 방식으로 제작하지 않는다. 다음 요소를 실제로 움직이게 구현한다.

- **카메라:** 웨이퍼를 향한 느린 푸시인과 미세한 시차 이동
- **정보 패널:** 서로 다른 깊이에서 미세한 패럴랙스와 제한적인 부유 움직임
- **문서 카드:** 일부 카드가 천천히 이동하거나 각도를 바꾸며 탐색되는 느낌을 연출
- **데이터 스트림:** 문서와 공정 데이터 패널을 연결하는 골드 빛과 입자
- **웨이퍼:** 표면 반사광과 링 조명의 흐름, 미세한 빛의 이동
- **텍스트:** 메인 문구와 보조 문구를 시간차를 두고 등장
- **조명:** 시작은 어둡게, 자료가 연결될 때 골드 조명을 강화하고 문구 등장 시 중앙의 대비를 높인다.

움직임은 고급스럽고 절제된 수준으로 유지한다. 빠른 회전, 강한 흔들림, 과도한 글로우, 폭발적인 전환은 사용하지 않는다.

## 5. 사운드

- 배경음악: 세련되고 절제된 시네마틱 전자음. 별도 나레이션은 사용하지 않는다.
- 시작: 낮은 저음과 함께 정보 패널이 드러나는 소리.
- 정보 탐색·연결: 은은한 상승음과 짧은 전자음.
- 메인 문구 등장: 부드러운 임팩트 사운드.
- 보조 문구 등장: 짧은 공명음을 사용한다.
- 종료: 다음 영상과 이어질 수 있도록 음악을 완전히 끊지 않고 짧게 정리한다.

## 6. 정확성 및 금지사항

- 화면에 서머리 번호나 `SUMMARY` 문구를 표시하지 않는다.
- 화면 문구는 아래 문구만 사용한다.
  - `필요한 지식을 찾아`
  - `업무에 활용하다`
  - `흩어진 정보 속에서 필요한 지식을 찾고,`
  - `관련 데이터와 연결해 더 나은 업무 판단을 지원합니다.`
- 문구를 임의로 변경하거나 추가 설명을 넣지 않는다.
- 특정 과제에만 해당하는 기능이 모든 과제의 공통 기능처럼 보이도록 표현하지 않는다.
- 성과 수치, 과제명, 담당자명, 불필요한 크레딧은 넣지 않는다.
- 확정 시안의 검정·골드 색상, 웨이퍼 중심 구도, 좌우 정보 패널, 중앙 문구를 유지한다.
- 정지 이미지 슬라이드쇼가 아닌 실제 모션을 구현한다.
