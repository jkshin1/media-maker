## 1. 제작 목표

엔지니어가 대면적 Plug 이미지를 육안으로 검증하던 업무에서 출발해, CV 기반 계측선과 Plug를 분석해 자동 인식하고 오계측 의심 항목을 선별한 뒤, 담당자가 최종 판단하는 흐름을 보여준다. 이어서 CD Profile 및 Space Profile 조회, 대시보드와 분석 챗봇을 통한 결과 활용까지 연결한다.

영상은 기존 시안의 5컷을 기준으로 제작한다. 각 컷 상단에는 명사형 장면 제목, 하단에는 나레이션을 배치한다. 단순히 자동화만 강조하지 않고, 자동 인식·오계측 의심 항목 선별·담당자 최종 판단·Profile 조회·분석 결과 활용이라는 실제 흐름을 보여준다.

## 4. 컷별 제작 지시

권장 본편 길이: 약 35–40초. 타이틀 화면은 별도 2–3초로 구성한다.

### CUT 1 — 대면적 데이터 수동 검증

**나레이션**
> 엔지니어가 육안으로 검증하던 업무를,

**화면 구성**
- 대면적 Plug 이미지가 다수 배열된 화면과 수동으로 확인하는 엔지니어를 보여준다.
- 별도 데이터 목록이나 이미지별 확인 작업이 함께 보이도록 구성한다.
- 기존 시안의 핵심은 대면적 이미지에 대한 수동 검증 업무이므로, 불필요한 다른 업무나 수치를 추가하지 않는다.

**카메라·모션**
- 대면적 Plug 이미지 배열을 따라 천천히 이동한다.
- 엔지니어가 화면을 확인하는 모습과 이미지 목록을 번갈아 보여준다.
- 여러 이미지가 반복적으로 확인되는 흐름을 강조한 뒤 CUT 2의 이미지 분석 화면으로 전환한다.

**상단 제목:** `대면적 데이터 수동 검증`

### CUT 2 — 계측 이미지 분석 및 자동 인식

**나레이션**
> CV로 계측선과 Plug를 분석해 자동으로 인식합니다.

**화면 구성**
- 대면적 Plug 이미지 위에 계측선 또는 검출 영역이 표시되는 모습을 보여준다.
- 이미지별 Plug가 인식되고 번호가 부여되는 흐름을 표현한다.
- 서로 다른 배율이나 간격에서도 대상이 식별되는 기능은 실제 과제 구현 범위에서만 표현한다.
- AI가 모든 이미지를 완벽하게 판정하는 것처럼 과장하지 않는다.

**카메라·모션**
- 이미지 위에 검출 프레임과 계측선이 순차적으로 나타난다.
- 인식된 Plug에 번호가 부여되며, 이미지 타일이 차례로 활성화된다.
- 자동 인식 결과가 CUT 3의 검토 목록으로 이어진다.

**상단 제목:** `계측 이미지 분석 및 자동 인식`

### CUT 3 — 오계측 탐지 및 검토 대상 선별

**나레이션**
> 오계측 의심 항목을 자동으로 선별하고, 담당자가 최종 판단합니다.

**화면 구성**
- 오계측 의심 이미지와 정상 이미지가 구분되어 나타난다.
- 의심 항목 목록에서 검토 대상이 강조되는 모습을 보여준다.
- 최종 판단은 담당자가 수행하는 Human-in-the-loop 흐름으로 표현한다.
- 자동으로 최종 확정하거나 모든 오류를 완벽하게 제거하는 것처럼 표현하지 않는다.

**카메라·모션**
- 의심 항목과 정상 항목이 목록에서 구분되어 강조된다.
- 검토 대상 항목이 선택되고 상세 이미지가 확대된다.
- 담당자의 최종 확인을 상징하는 선택 동작 후 CUT 4의 Profile 조회 화면으로 전환한다.

**상단 제목:** `오계측 탐지 및 검토 대상 선별`

### CUT 4 — Profile 조회 및 데이터 확인

**나레이션**
> Plug의 CD와 Space Profile을 조회하고 데이터를 확인합니다.

**화면 구성**
- CD Profile 및 Space Profile 조회 화면을 보여준다.
- Lot, Device, Plug ID 등 기존 시안에 포함된 선택 항목과 Profile 그래프를 활용한다.
- Point별 그래프와 데이터 확인 화면을 보여주되, 시안에 없는 분석 지표나 자동 원인 판정은 추가하지 않는다.
- 화면 속 구체적인 Lot ID, 측정값, 그래프 값은 승인된 원본 자료에서 확인된 경우에만 사용한다.

**카메라·모션**
- CD Profile과 Space Profile 탭이 순차적으로 전환된다.
- Point별 그래프가 차례로 나타나고, 선택된 데이터가 부드럽게 강조된다.
- 조회 결과가 CUT 5의 대시보드·챗봇 화면으로 이어진다.

**상단 제목:** `Profile 조회 및 데이터 확인`

---

### CUT 5 — 대시보드·챗봇 및 분석 환경 지원

**나레이션**
> 대시보드와 챗봇으로 분석 결과를 업무에 활용합니다.

**화면 구성**
- 대시보드의 요약 지표와 결과 테이블을 보여준다.
- 분석 챗봇을 통해 결과에 대한 질문과 답변을 확인하는 화면을 표현한다.
- 프로파일 조회, 결과 테이블, 챗봇은 기존 시안에 있는 요소만 사용한다.
- 챗봇이 원인을 확정하거나 자동으로 공정을 제어하는 것처럼 표현하지 않는다.
- 대시보드에 표시되는 건수와 측정값은 승인된 실제 자료에서 확인되는 경우에만 사용한다.

**카메라·모션**
- 대시보드의 요약 카드와 데이터 테이블이 순서대로 나타난다.
- 챗봇 대화창에 질문과 답변이 자연스럽게 표시된다.
- 마지막에는 대시보드와 챗봇이 함께 보이는 구도로 정리하고 다음 과제로 연결한다.

**상단 제목:** `대시보드·챗봇 및 분석 환경 지원`
