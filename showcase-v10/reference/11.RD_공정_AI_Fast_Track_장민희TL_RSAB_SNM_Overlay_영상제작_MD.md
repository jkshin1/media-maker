### CUT 1 — Overlay 분석 도구별 개별 조회

**나레이션**
> Overlay 분석 도구별로 데이터를 조회하고 담당자의 지식에 의존해 열화 원인을 분석하던 업무를,

**화면 구성**
- 여러 분석 도구와 데이터 화면을 동시에 띄워둔 연구 환경을 보여준다.
- Overlay 분석 도구, Residual 분석 도구, MA Bias 분석 도구, Dcol Data(Spec in/out) 등 기존 시안에 있는 화면을 활용한다.
- 연구원이 여러 화면을 확인하며 데이터를 비교하는 모습을 표현한다.
- 이 장면은 기존 업무의 분산과 반복 조회를 보여주는 데 집중한다.

**카메라·모션**
- 여러 분석 화면을 따라 좌우로 이동하는 카메라 트래킹.
- 각 도구 창이 순차적으로 강조되고, 연구원의 시선이 화면 사이를 이동한다.
- 마지막에 여러 창의 정보가 하나의 Lot ID 입력 화면으로 전환되며 CUT 2로 연결된다.

**상단 제목:** `Overlay 분석 도구별 개별 조회`

### CUT 2 — Lot ID 통합 조회

**나레이션**
> Lot ID 하나로 필요한 데이터를 통합 조회합니다.

**화면 구성**
- RSAB SNM Overlay AI Agent 인터페이스를 중심으로 구성한다.
- Lot ID 입력창을 강조하고, 입력 후 Overlay Map, Residual Map, MA Bias Map, Trend 분석, K-parameter 분석 메뉴가 나타나는 흐름을 보여준다.
- 기존 시안의 `RSAB250`은 예시 화면에 포함되어 있으나, 실제 영상에서는 승인된 원본 화면의 Lot ID를 사용하거나 실제 데이터로 오해되지 않도록 데모용 값임을 분명히 한다.
- 별도의 기능이나 메뉴를 임의로 추가하지 않는다.

**카메라·모션**
- AI Agent 화면으로 푸시인.
- Lot ID 입력이 자연스럽게 나타나고 조회 동작 후 분석 항목이 순차적으로 활성화된다.
- 각 항목은 빠르고 명확하게 강조하되, 읽기 어려울 정도로 빠르게 지나가지 않는다.

**상단 제목:** `Lot ID 통합 조회`

### CUT 3 — 다양한 Map으로 공정 상태 확인

**나레이션**
> Overlay, Residual, MA Bias를 Vector·Scatter Map으로 확인합니다.

**화면 구성**
- Overlay, Residual, MA Bias 관련 Map을 기존 시안처럼 주요 영역에 배치한다.
- 웨이퍼 위치별 패턴과 분포를 비교할 수 있도록 구성한다.
- 시안에 있는 범례와 색상 스케일은 원본 자료에서 확인되는 경우 그대로 사용한다.
- Map에 임의의 공정 원인이나 확정 판정을 표시하지 않는다.

**카메라·모션**
- Map이 순서대로 활성화되고, 각 웨이퍼 분포에 색상 변화가 부드럽게 나타난다.
- 카메라 포커스를 Overlay Map에서 Residual, MA Bias Map으로 이동한다.
- 각 Map의 전체 형태를 충분히 보여준 뒤 CUT 4로 전환한다.

**상단 제목:** `다양한 Map으로 공정 상태 확인`

### CUT 4 — 주요 Parameter Trend 비교

**나레이션**
> 주요 Overlay Parameter의 Trend를 비교하고, 정상 대비 Wafer 분포를 확인합니다.

**화면 구성**
- 기존 시안의 Parameter Trend(박스플롯)와 정상 Baseline 대비 입력 Wafer 위치 분포를 보여준다.
- 정상 Baseline과 입력 Wafer의 비교 구조를 명확하게 표현한다.
- 임의의 수치, Lot 결과, 장비 조건을 만들어 넣지 않는다.
- 실제 원본 자료에 있는 축·범례·Parameter 명칭만 사용한다.

**카메라·모션**
- Trend 그래프가 먼저 나타나고 데이터 포인트 또는 박스플롯이 순차적으로 강조된다.
- 이어서 Wafer 위치 분포 화면으로 포커스가 이동한다.
- 정상 Baseline과 입력 Wafer 표시가 구분되도록 시각적으로 강조한다.

**상단 제목:** `주요 Parameter Trend 비교`

### CUT 5 — K-parameter 분석으로 원인 추정

**나레이션**
> K-parameter를 정상 Baseline 대비 Z-score로 평가해 의심 공정 계층을 추정하고, 원인별 솔루션을 제시합니다.

**화면 구성**
- 기존 시안의 K-parameter 분석 결과와 의심 공정 계층 추정 영역을 보여준다.
- 원인 추정은 확정 판정이 아니라 의심 계층을 좁히는 분석 결과로 표현한다.
- 장비 정렬/Reticle, 노광, CMP, PR 등은 실제 시안 및 원본 자료에 포함된 항목 범위에서만 표시한다.
- 시안에 포함된 솔루션 예시를 보여줄 때는 실제 기능 범위를 넘어서 자동 보정이나 자동 실행이 이루어지는 것처럼 표현하지 않는다.
- 성과 수치는 공식 자료와 일치하는 경우에만 별도 자막으로 사용한다. 기존 시안의 `분석 시간 15분~1시간 → 건당 수분`을 넣을 경우 승인된 원본 성과 자료에서 다시 확인한다.

**카메라·모션**
- K-parameter 결과표에서 Z-score 열과 의심 항목을 차례로 강조한다.
- 의심 공정 계층 영역으로 카메라가 이동하고, 솔루션 제안 항목이 순차적으로 나타난다.
- 마지막에는 결과 화면을 짧게 유지하고 다음 과제로 자연스럽게 연결한다.

**상단 제목:** `K-parameter 분석으로 원인 추정`
