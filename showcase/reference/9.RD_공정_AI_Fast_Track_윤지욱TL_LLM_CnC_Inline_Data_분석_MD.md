> 담당: 윤지욱 TL

## 1. 제작 목표

기존에는 C&C Inline Data를 조건별로 조회하고 이상 여부를 확인하던 업무에서 출발한다. 사용자가 LLM에 자연어로 분석을 요청하면 관련 데이터를 연결하고, GoodDocs 매핑과 상관관계 분석을 수행해 분석 결과를 시각화하고 연계 공정을 선별하는 흐름을 보여준다.

**핵심 흐름:** 기존 데이터 조회 → 자연어 기반 분석 질의 → 관련 데이터 연계·분석 → 분석 결과 시각화 → 분석 효율 및 의사결정 향상

본 영상은 승인된 스토리보드의 검정·골드 스타일을 유지하되, 각 컷을 독립된 움직이는 장면으로 구현한다. 스토리보드 이미지를 통째로 정지 화면으로 사용하지 않는다.

## 2. 공통 제작 규칙 적용

첨부된 `RD_AI_Fast_Track_공통_제작_규칙_타이틀화면추가.md`를 함께 참고하고 준수한다.

- 화면 비율: 16:9 가로형
- 해상도: 1920 × 1080 이상
- 출력: MP4, H.264 영상 / AAC 오디오 권장, 30 fps 권장
- 색상: 검정 `#080808`, 차콜 `#1A1A1F`, 골드 `#D4AF7C`, 웜 골드 `#F5D6A6`, 앰버 `#FFB347`, 웜 화이트 `#F2EEE7`
- 시각 스타일: 프리미엄 반도체 R&D, 현실적인 장비·웨이퍼·데이터 화면, 절제된 골드 조명
- 과도한 파란 네온이나 불필요한 SF 장식은 사용하지 않는다.
- 공통 디자인은 유지하되, 이번 과제는 C&C Inline Data 조회·관련 데이터 연결·상관관계 분석·결과 시각화를 중심으로 차별화한다.
- 승인된 스토리보드와 실제 과제 기능을 임의로 변경하지 않는다.
- 실제 자료에 없는 기능·성과·수치를 만들지 않는다.
- 텍스트는 영상 생성 모델이 그리게 하지 말고, 편집 단계에서 정확히 삽입한다.
- 스토리보드 전체를 정지 화면으로 사용하거나, 이미지 다섯 조각을 잘라 슬라이드쇼처럼 붙이지 않는다. 각 컷을 독립된 장면으로 구현하고 실제 카메라 움직임과 UI 애니메이션을 적용한다.

**권장 시간:** 0–6초

**나레이션**
> C&C Inline Data를 조건별로 조회하고 이상 여부를 확인하던 업무를,

**화면 구성**
- 연구원이 C&C Inline Data 화면에서 조건별 데이터를 조회하는 장면.
- 조회 조건과 데이터 표가 있는 화면을 보여준다.
- 여러 항목을 확인하는 기존 업무의 흐름을 표현한다.
- 화면 내 구체적인 Fab, Tool, Recipe, 날짜, Lot ID, 수치는 실제 제공 자료로 확인된 경우에만 사용한다. 확인되지 않은 경우 일반적인 UI 요소로 표현하고 실제 데이터처럼 보이는 가짜 숫자를 강조하지 않는다.

**카메라·모션**
- 연구원 어깨 너머에서 데이터 화면으로 천천히 푸시인.
- 조회 조건이 순서대로 강조되고 결과 표가 나타나는 모션.
- 카메라는 표와 조회 조건 사이를 짧게 이동한다.
- 마지막에 조회 화면의 입력 영역이 강조되며 CUT 2로 전환한다.

**화면 제목**

### CUT 2 — 자연어 기반 분석 질의
**권장 시간:** 6–12초

**나레이션**
> LLM에 자연어로 분석을 요청하고,

**화면 구성**
- 연구원이 LLM 기반 AI Agent에 분석 질문을 입력한다.
- 질문은 Spec-out 사례를 분석하기 위한 요청이라는 맥락을 전달한다.
- 실제 제공 자료에 구체적인 질문 문구가 있으면 그대로 사용한다. 없으면 기능을 과장하지 않는 일반적인 질문으로 구성한다.
- 자동 이상 원인 판정이나 자동 조치 기능이 있는 것처럼 표현하지 않는다.

**카메라·모션**
- 연구원과 AI 인터페이스가 함께 보이는 장면에서 질문 입력창으로 푸시인.
- 질문 텍스트가 자연스럽게 입력된다.
- 전송 후 UI가 부드럽게 전환되며 CUT 3의 데이터 연계 장면으로 연결된다.

**화면 제목**
`자연어 기반 분석 질의`

### CUT 3 — 관련 데이터 연계·분석
**권장 시간:** 12–19초

**나레이션**
> GoodDocs 매핑과 상관관계 분석으로 관련 정보를 연결하고,

**화면 구성**
- C&C Inline Data와 GoodDocs를 연결해 관련 정보를 찾는 흐름을 표현한다.
- 관련 공정 데이터와 분석 요소가 연결되고, 상관관계 분석 결과가 정리되는 모습을 보여준다.
- 과제의 핵심 기능인 GoodDocs 매핑, 상관관계 분석, 연계 공정 선별을 중심으로 표현한다.
- 시안에 나온 Recipe 번호, 상관관계 계수, 원인 순위, 장비 조건 등은 실제 자료에서 확인되지 않으면 사용하지 않는다.
- AI가 확정적인 원인을 자동 판정하거나 공정을 자동 실행하는 것으로 표현하지 않는다.

**카메라·모션**
- C&C Inline Data와 GoodDocs 패널이 순차적으로 나타난다.
- 두 패널 사이에 골드 연결선이 형성된다.
- 관련 공정 정보가 연결된 뒤 분석 영역으로 이동한다.
- 연결선과 패널이 동시에 과도하게 번쩍이지 않도록 차분하게 애니메이션을 적용한다.

**화면 제목**
`관련 데이터 연계·분석`

### CUT 4 — 분석 결과 시각화
**권장 시간:** 19–27초

**나레이션**
> 분석 결과를 시각화하고 연계 공정을 선별해,

**화면 구성**
- 분석 결과를 그래프와 관련 공정 정보로 정리해 보여준다.
- 실제 과제에서 지원하는 결과 형식에 맞춰 시각화를 구성한다.
- 연계 공정 선별 결과를 확인할 수 있는 영역을 보여준다.
- Wafer Map, 이상 패턴 자동 탐지, 원인 순위, 특정 그래프 등은 실제 기능과 자료로 확인된 경우에만 사용한다. 근거가 없으면 일반적인 상관관계 시각화와 연계 공정 결과로 표현한다.

**카메라·모션**
- 분석 결과 패널로 부드럽게 푸시인.
- 그래프는 선이 그려지거나 데이터 포인트가 순차적으로 나타나는 모션을 사용한다.
- 연계 공정 결과는 행 또는 항목이 차례로 강조된다.
- 컷의 마지막에 결과 화면이 정돈되며 CUT 5로 이어진다.

**화면 제목**

- 복잡한 데이터 조회에서 정리된 분석 결과로 전환된 변화를 시각적으로 보여준다.
- 마지막은 연구원 화면과 반도체 웨이퍼 또는 공정 장비를 함께 보여주며 마무리한다.
- `분석 시간 70% 이상 단축` 수치는 공식 과제 자료에서 정확히 확인된 경우에만 표시한다. 확인되지 않으면 수치를 생략한다.

**카메라·모션**
- 연구원과 분석 화면을 함께 담은 미디엄 샷.
- 분석 화면에서 웨이퍼 또는 장비로 시선이 이동하도록 카메라를 부드럽게 이동한다.
- 골드 조명으로 짧게 마무리하고 다음 과제로 연결할 수 있게 종료한다.

**화면 제목**
`분석 효율 및 의사결정 향상`

- 실제 자료에서 확인되지 않은 기능·수치·결과를 임의로 추가하지 않는다.

- 자동 이상 원인 확정, 자동 조치, 자동 공정 실행 등 확인되지 않은 기능을 추가하지 않는다.
- `분석 시간 70% 이상 단축`은 공식 과제 자료에서 검증된 경우에만 사용한다.

- 시안에 포함된 장식용 UI는 실제 기능으로 오해되지 않게 최소화하거나 검증된 화면으로 대체한다.
- 공통 디자인은 유지하되, 다른 과제와 차별화되도록 데이터 연계·분석·시각화에 초점을 맞춘다.
