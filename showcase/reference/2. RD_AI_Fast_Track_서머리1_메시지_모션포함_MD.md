# 흩어진 정보를 연결해 더 넓은 가능성을 열다
## 서머리 메시지 영상 제작 MD

> 목적: 확정된 단일 장면 시안을 기준으로 약 6–8초 길이의 시네마틱 모션 영상을 제작한다.  
> 중요: 화면에 `SUMMARY 1`, `SUMMARY 2`, `SUMMARY 3` 등 서머리 번호나 라벨을 표시하지 않는다.

---

## 1. 영상 콘셉트

**메인 문구**
- 1행: `흩어진 정보를 연결해`
- 2행: `더 넓은 가능성을 열다`

**보조 문구**
- 1행: `AI가 다양한 데이터와 지식을 연결해`
- 2행: `더 정확하고 빠른 R&D 인사이트를 만듭니다.`

이 장면은 여러 시스템과 자료에 분산된 정보가 연결되어 R&D 업무에 활용될 수 있다는 메시지를 전달한다. 개별 과제의 기능을 나열하지 않고, 정보와 지식의 연결이라는 공통 가치를 강조한다.

## 2. 공통 디자인 규칙

- 화면 비율: 16:9 가로형
- 권장 해상도: 1920 × 1080
- 권장 프레임레이트: 30 fps
- 시각 스타일: 검정·차콜 배경, 골드·앰버 포인트, 프리미엄 반도체 R&D 분위기
- 기본 색상:
  - Black: `#080808`
  - Charcoal: `#1A1A1F`
  - Gold: `#D4AF7C`
  - Light Gold: `#F5D6A6`
  - Amber: `#FFB347`
  - Cream: `#F2EEE7`
- 확정 시안의 웨이퍼 중심 구도, 좌우 데이터 패널, 중앙 문구, 골드 데이터 스트림을 유지한다.
- `SUMMARY 1`, `SUMMARY 2`, `SUMMARY 3`, `SUMMARY 4` 등의 번호·영문 라벨을 추가하지 않는다.
- 과제명, 담당자명, 과제 번호를 넣지 않는다. 이 영상은 개별 과제 소개가 아니라 서머리의 종합 메시지 장면이다.
- 문구는 정확한 한국어 텍스트 레이어로 구현한다. 이미지에 포함된 글자를 그대로 사용해 오탈자가 노출되지 않도록 한다.
- 실제 기능으로 확인되지 않은 수치나 기능을 새로 추가하지 않는다.

## 3. 길이 및 타임라인

총 길이: 약 6–8초. 단일 장면을 유지하되 카메라·조명·데이터 패널·텍스트가 실제로 움직이도록 제작한다.

### 0.0–1.5초 — 데이터 패널이 어둠 속에서 드러남
- 시작은 어두운 반도체 R&D 공간.
- 좌우 데이터 패널의 윤곽과 골드 테두리 조명이 순차적으로 켜진다.
- 패널은 서로 다른 깊이에 배치되어 입체감을 형성한다.
- 카메라는 중앙 웨이퍼를 향해 천천히 전진한다.
- 메인 문구는 아직 완전히 표시하지 않는다.

### 1.5–3.0초 — 흩어진 정보가 연결되기 시작
- 좌우 패널에서 중앙과 웨이퍼 방향으로 골드 데이터 스트림이 흐른다.
- 연결선은 각각 다른 속도와 경로로 움직이며 정보가 한곳으로 모이는 느낌을 준다.
- 패널은 작은 패럴랙스와 밝기 변화로 움직인다. 과도하게 회전하거나 화면 밖으로 튀어나오지 않는다.
- 웨이퍼 표면에는 미세한 빛이 이동한다.

### 3.0–4.5초 — 메인 문구 등장
- 중앙 문구를 두 단계로 표시한다.
  1. `흩어진 정보를 연결해`
  2. `더 넓은 가능성을 열다`
- 첫 번째 줄이 부드럽게 등장한 뒤, 두 번째 줄이 골드 강조와 함께 이어서 나타난다.
- 두 번째 줄의 골드 색상과 강조는 시안의 디자인을 유지한다.
- 텍스트는 중앙 정렬을 유지하고, 데이터 패널이나 웨이퍼를 과도하게 가리지 않는다.

### 4.5–6.5초 — 보조 문구와 웨이퍼 조명 강조
- 보조 문구를 두 줄로 순차적으로 표시한다.
  - `AI가 다양한 데이터와 지식을 연결해`
  - `더 정확하고 빠른 R&D 인사이트를 만듭니다.`
- 웨이퍼 가장자리의 골드 링 조명이 한 차례 흐르듯 이동한다.
- 좌우 패널의 데이터 그래프와 연결망이 미세하게 움직인다.
- 카메라는 아주 천천히 전진해 화면에 깊이감을 더한다.

### 6.5–8.0초 — 메시지 유지 및 자연스러운 전환
- 모든 문구를 읽을 수 있도록 짧게 유지한다.
- 배경 데이터 스트림과 조명은 미세하게 계속 움직인다.
- 다음 영상으로 연결할 경우 골드 데이터 스트림이 화면 가장자리로 흐르며 자연스럽게 전환한다.
- 별도 엔딩 크레딧이나 서머리 번호를 추가하지 않는다.

## 4. 모션 구현 지침

단순히 확정 시안 이미지를 확대하거나 축소하는 방식으로 제작하지 않는다. 다음 요소를 실제로 움직이게 구현한다.

- **카메라:** 웨이퍼를 향한 느린 푸시인과 미세한 시차 이동
- **데이터 패널:** 서로 다른 깊이에서 미세한 패럴랙스와 제한적인 부유 움직임
- **데이터 스트림:** 좌우 패널에서 중앙 및 웨이퍼 방향으로 흐르는 골드 빛과 입자
- **웨이퍼:** 표면 반사광과 링 조명의 흐름, 미세한 빛의 이동
- **텍스트:** 메인 문구와 보조 문구를 시간차를 두고 등장
- **조명:** 시작은 어둡게, 데이터 연결 시 골드 조명을 강화하고 문구 등장 시 중앙의 대비를 높인다.

움직임은 고급스럽고 절제된 수준으로 유지한다. 빠른 회전, 강한 흔들림, 과도한 글로우, 폭발적인 전환은 사용하지 않는다.

## 5. 사운드

- 배경음악: 세련되고 절제된 시네마틱 전자음. 나레이션은 사용하지 않는다.
- 시작: 낮은 저음과 함께 패널 조명이 켜지는 소리.
- 데이터 연결: 은은한 상승음과 짧은 전자음.
- 메인 문구 등장: 부드러운 임팩트 사운드.
- 보조 문구 등장: 짧은 공명음을 사용한다.
- 종료: 다음 영상과 이어질 수 있도록 음악을 완전히 끊지 않고 짧게 정리한다.

## 6. 정확성 및 금지사항

- 화면에 서머리 번호나 `SUMMARY` 문구를 표시하지 않는다.
- 화면 문구는 아래 문구만 사용한다.
  - `흩어진 정보를 연결해`
  - `더 넓은 가능성을 열다`
  - `AI가 다양한 데이터와 지식을 연결해`
  - `더 정확하고 빠른 R&D 인사이트를 만듭니다.`
- 문구를 임의로 변경하거나 추가 설명을 넣지 않는다.
- 특정 과제에만 해당하는 기능이 모든 과제의 공통 기능처럼 보이도록 표현하지 않는다.
- 성과 수치, 과제명, 담당자명, 불필요한 크레딧을 넣지 않는다.
- 확정 시안의 검정·골드 색상, 웨이퍼 중심 구도, 좌우 데이터 패널, 중앙 문구를 유지한다.
- 정지 이미지 슬라이드쇼가 아닌 실제 모션을 구현한다.
