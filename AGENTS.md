# Media Maker production defaults

- The active full production is under `production/`, driven by `production/storyboard.json` and `production/narration/ko.json`; final outputs are under `out/production/`. Keep the approved 18-second sample separately in `src/`, `assets/narration/`, and its existing output paths.
- Each task introduction lasts exactly 18 seconds: a 2-second title and four 4-second content cuts (BEFORE, AFTER input/integration, AFTER analysis, BEFORE/AFTER comparison). The full film lasts 241 seconds: opening 15, tasks 216, ending 10.
- For each task BEFORE cut, use a task-specific photograph of the actual manual work or information-search problem. Vary action, person, props, camera angle and workspace; do not repeat a generic man resting his chin in thought. Save assets and prompts under `production/assets/before/`. Keep the source concept images intact.
- For the current production, do not overlay descriptive labels on the task BEFORE photographs. Keep the separate narration captions. The first task title cut uses larger task-title and team/owner type (84px and 46px at 1920x1080) with deliberate line breaks.
- Match this production's concept images with large photographed workspaces and angled monitor compositions. Keep task-specific UI motion active within each content cut: query typing, data flow, graph drawing, scans, measurement lines, or photographic Before/After wipes. Drive animation from the explicit scene time so frame rendering is repeatable. Use approved Before photographs for title backgrounds, and exclude source-image name typos and unverified performance figures from the composed scenes.
- For this production, omit brief NEXT cards between tasks. Hold the previous task body until the next full task title appears; keep the task introduction order and the separate ending.
- Follow direct user name corrections over image typography. For this production, the research Infra owner is 곽재오 TL and the C&C Inline Data owner is 윤지욱 TL. Within the task introductions, 장민희 and 김지은 are the final two, followed by a separate ending.
- Read `production/narration/ko.json` before producing or replacing full-production narration; read `assets/narration/ko.json` for the approved sample. The active config's saved engine, voice, model, delivery tag, voice settings, scene timing, and BGM are the user's defaults.
- Use `npm run production:prompts` for full-production ElevenLabs inputs, or `npm run tts:prompts` for the sample. The selected default voice is Salang - Calm, Clear and Warm (`mYk0rAapHek2oTw18z8x`). Use the saved default voice with the same bright, confident presentation delivery unless the user requests another voice or style.
- Vary each task BEFORE narration to describe its specific manual-work problem naturally. End task narration blocks with complete polite Korean sentences in `-니다.`; avoid fragments such as `...로.`. Keep spoken text and narration captions synchronized.
- The default `generation_mode` is `single_take`: generate the entire narration in one request using the top-level `generated_prompt`, with the delivery tag once. Split that continuous take at pauses and place the clips at the saved scene timings. Do not generate each scene independently; one take helps maintain the same tone across scenes.
- Check cut points against both transcript word boundaries and waveform pauses. Low signal can occur inside a Korean word; silence detection alone is insufficient to confirm a sentence boundary.
- Verify that every narration block and the ending are actually spoken before importing a new take. A completed generation record and matching full prompt do not prove that the audio contains the entire script. Use the installed local Whisper when possible to avoid sending audio to another service.
- For new narration, use the saved model and voice settings in the connected ElevenLabs service. Import the 48000 Hz mono master into the active production's `narration/elevenlabs/take.wav`, the unmodified cuts as `vo1.wav` etc., and their exact prompts, settings, SHA-256 provenance, and sample cut boundaries in `manifest.json`; the terminal importer does not generate remote speech. Each cut must match the corresponding samples in the master. Sample assets stay under `assets/narration/elevenlabs/`.
- `npm run production:audio` applies the saved BGM and mixes full-production narration onto `out/production/video_silent.mp4`; `npm run audio` is for the sample. Verify duration, frame count, audio decoding, scene timing, and the copied video stream before delivering a completed video.
