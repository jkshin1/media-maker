# TCAD-TEM 이미지 연계를 통한 이미지 Labeling Tool 개발
## 김성후 TL 과제 영상 제작 MD

> 제작 기준: 사용자가 제공한 기존 5컷 스토리보드 이미지  
> 조직: DRAM ETCH  
> 담당: 김성후 TL  
> 화면 비율: 16:9  
> 중요: 기존 시안의 5컷 구성, 상단 제목, 하단 나레이션, 핵심 기능 흐름을 유지한다. 확인되지 않은 기능이나 성과 수치는 임의로 추가하지 않는다.

## 1. 제작 목표

TEM 이미지 분석에서 반복되는 수작업을 줄이기 위해, 하나의 Tool에서 이미지 회전·정렬, 측정 항목별 자동 측정, Raw data 정리, 데이터 분석 및 시각화를 연결하는 흐름을 보여준다. 기존 시안의 메시지를 유지하며 이미지 측정 시간 단축과 분석 결과 개선 효과를 마지막 컷에서 전달한다.

- 스토리보드 이미지 전체를 정지 화면으로 사용하지 않는다. 각 컷을 독립된 영상 장면으로 제작한다.
- 카메라 이동, 이미지 회전·정렬, 측정 프레임 표시, Raw data 표 구성, 그래프 시각화에 실제 모션을 적용한다.

- 최종 결과물은 MP4, 실행 가능한 소스 코드, 실행 방법 안내를 포함한다.

## 4. 컷별 제작 지시

권장 본편 길이: 약 35–40초. 타이틀 화면은 별도 2–3초로 구성한다.

### CUT 1 — 반복되는 수작업 분석

**나레이션**
> TEM 이미지 분석에 반복되는 수작업이 많습니다.

**화면 구성**
- 여러 TEM 이미지가 화면에 펼쳐져 있고, 엔지니어가 이미지 회전, 항목별 측정, Raw data 정리, 수동 분석을 반복하는 업무 환경을 보여준다.
- 이미지별로 확인해야 하는 반복 작업을 시각적으로 구분한다.
- 기존 시안에 있는 `이미지 회전`, `항목별 측정`, `Raw data 정리`, `수동 분석` 문구를 정확하게 사용한다.

**카메라·모션**
- TEM 이미지 화면을 따라 천천히 이동한다.
- 이미지 회전, 측정, Raw data 정리 항목이 차례로 강조된다.
- 여러 이미지가 반복적으로 확인되는 흐름을 보여준 뒤 CUT 2의 통합 Tool 화면으로 연결한다.

**상단 제목:** `반복되는 수작업 분석`

---

### CUT 2 — 이미지 분석 자동화 Tool

**나레이션**
> 하나의 Tool에서 이미지 측정부터 데이터 분석까지 자동으로 처리합니다.

**화면 구성**
- `TCAD-TEM Labeling Tool` 인터페이스를 중심으로 구성한다.
- 이미지 불러오기, 이미지 회전 및 정렬, 측정 항목별 자동 측정, Raw data 정리, 데이터 분석 및 시각화 메뉴를 기존 시안대로 보여준다.
- 측정 항목 및 버튼 이름은 시안의 표현을 유지한다.
- 실제 구현 범위에 없는 기능을 메뉴에 추가하지 않는다.

**카메라·모션**
- Tool 화면으로 부드럽게 푸시인한다.
- 메뉴가 순서대로 활성화되고, TEM 이미지가 화면에 불러와진다.
- 이미지 회전·정렬이 적용되는 모습을 짧게 보여준 뒤 CUT 3으로 연결한다.

**상단 제목:** `이미지 분석 자동화 Tool`

---

### CUT 3 — 측정 항목별 자동 측정

**나레이션**
> 이미지를 회전하고, 항목별로 자동 측정해 Raw data까지 정리합니다.

**화면 구성**
- TEM 이미지 위에 측정 프레임과 측정선이 나타나는 모습을 보여준다.
- 기존 시안의 측정 항목인 `R_NIT`, `S/W`, `CD`, `LS`, `Etch Depth`, `Sidewall Angle`을 정확히 표기한다.
- 측정 결과가 Raw data 표로 정리되는 모습을 보여준다.
- 이미지 예시 및 측정값은 승인된 원본 자료에서 확인되는 경우에만 사용한다.

**카메라·모션**
- 이미지 회전·정렬이 적용되고 측정 프레임이 순서대로 나타난다.
- 측정 항목이 체크되면서 측정 결과 표의 행이 차례로 채워진다.
- 숫자와 단위가 실제 원본 자료와 일치하는지 확인하고, 확인되지 않으면 임의 수치 대신 중립적인 UI를 사용한다.

**상단 제목:** `측정 항목별 자동 측정`

---

### CUT 4 — 데이터 분석 및 시각화

**나레이션**
> 정리된 데이터를 기반으로 분석 결과를 시각화해 정확한 인사이트를 제공합니다.

**화면 구성**
- 분석 결과 비교 패널과 그래프를 보여준다.
- 기존 시안에 있는 `R_NIT 정확도`, `S/W 정확도`, `R_NIT vs S/W` 시각화 영역을 기준으로 구성한다.
- 기존 대비 개선 결과를 표현하되, 구체적인 수치는 승인된 원본 자료에서 확인되는 경우에만 표시한다.
- 추가적인 분석 지표나 해석을 임의로 만들어 넣지 않는다.

**카메라·모션**
- 비교 패널이 차례로 나타나고, 막대그래프가 아래에서 위로 그려진다.
- 산점도 또는 비교 그래프의 점들이 순차적으로 나타난다.
- 데이터가 정리되어 분석 결과로 이어지는 흐름을 보여준 뒤 CUT 5로 전환한다.

**상단 제목:** `데이터 분석 및 시각화`

---

### CUT 5 — 더 빠르고 정확한 분석 환경

**나레이션**
> 이미지당 측정 시간은 5분에서 6초로 줄고, R_NIT 정확도는 44%, S/W 정확도는 84% 개선됩니다.

**화면 구성**
- 기존 시안의 효과 지표 세 가지를 보여준다.
  - 이미지당 측정 시간: `5분 → 6초`
  - R_NIT 정확도: `44% 개선`
  - S/W 정확도: `84% 개선`
- 위 수치는 사용자가 제공한 시안에 표시된 내용이며, 최종 영상에 넣기 전에 승인된 원본 자료와 일치하는지 확인한다.
- `정확도`와 `개선율`의 의미를 임의로 바꾸거나, 퍼센트의 기준을 추정해 설명하지 않는다.
- 배경에는 TEM 이미지 분석 화면과 연구 환경을 사용한다.

**카메라·모션**
- 측정 시간 지표가 `5분`에서 `6초`로 전환되는 모션을 적용한다.
- 이어서 R_NIT와 S/W 개선 지표가 순서대로 강조된다.
- 마지막에 연구원이 정리된 분석 결과를 확인하는 모습으로 안정적으로 마무리한다.

**상단 제목:** `더 빠르고 정확한 분석 환경`
