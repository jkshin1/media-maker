# R&D 공정 AI Fast Track — Thinfilm Agent 영상 제작 MD

> **기준 시안:** 사용자가 제공한 「Thinfilm Agent - BEOL Thinfilm / 김태민 TL」 스토리보드 이미지를 시각적 기준으로 사용한다.
> **중요:** 딥블랙·골드·앰버 디자인과 5개 장면의 흐름은 유지하되, 시안의 세부 UI·수치 중 실제 자료에서 확인되지 않은 항목은 사실처럼 사용하지 않는다. 이 MD에 지정한 장면별 모션을 실제 영상으로 구현하며, 스토리보드 이미지 한 장을 그대로 영상으로 출력하지 않는다.

## 1. 과제 정보

- **과제명:** Thinfilm Agent - BEOL Thinfilm
- **담당:** 김태민 TL
- **핵심 메시지:** 여러 시스템에 분산된 Lot·장비·FDC 현황을 하나의 웹 플랫폼에서 확인하고, Summary Chart·시각화와 DOE 결과 업데이트·공유를 지원
- **주요 기능**
  - Lot·장비·FDC 현황 실시간 조회
  - Summary Chart 및 시각화
  - DOE 결과 업데이트 및 공유
  - DOE 분석 방법과 최적 조건 탐색 로직의 조직 자산화
- **기대 효과:** 업무 시간 단축, DOE 분석 효율화, 최적 조건 탐색 지원
- **영상 길이:** 약 20~25초
- **장면 수:** 5개
- **출력:** 16:9, 1920×1080 Full HD, 30fps, H.264/AAC MP4

## 2. 디자인 규칙

- 기존 R&D AI Fast Track 공통 제작 규칙을 우선 적용한다.
- 딥블랙 배경과 골드·앰버 조명, 크림색/화이트 타이포그래피를 유지한다.
- 색상 기준: 배경 `#080808`, 딥 차콜 `#1A1A1F`, 골드 `#D4AF7C`, 라이트 골드 `#F5D6A6`, 앰버 `#FFB347`, 보조 텍스트 `#F2EEE7`.
- 블루/네온 블루를 주조색으로 바꾸지 않는다. 그래프 안의 보조 색상은 필요한 경우에만 제한적으로 사용한다.
- 화면은 정지시키고 글자만 바꾸는 방식으로 제작하지 않는다. UI 패널, 그래프, 빛의 흐름, 카메라 이동, 장면 전환을 실제로 애니메이션 처리한다.
- 모든 한글 텍스트는 코드 또는 편집 도구로 정확하게 렌더링한다. 이미지 생성 결과에 포함된 글자를 그대로 사용하지 않는다.
- 과제명과 담당자명은 시작부에 간결하게 표시한다.
- 실제 플랫폼 화면이 제공되면 그 화면을 우선 사용한다. 실제 화면이 없다면 일반적인 대시보드 형태로 표현하되, 실제 기능으로 오해할 수 있는 가짜 상세 UI는 최소화한다.

## 3. 핵심 문구

**메인 메시지:**  
`분산된 정보를 하나의 플랫폼으로`

**보조 메시지:**  
`Lot·장비·FDC 현황 조회부터 DOE 결과 공유까지`

이 문구는 Thinfilm Agent의 범위를 요약하는 표현이다. 화면마다 동일 문구를 반복하지 말고, 각 장면은 기능 흐름을 보여준다.

## 4. 나레이션 — 장면 간 자연스럽게 연결

장면마다 문장을 완전히 끊어 읽지 않는다. CUT 1의 구절이 CUT 2로 이어지고, 전체가 하나의 설명처럼 들리도록 녹음·편집한다.

### 전체 나레이션
“여러 시스템과 자료에 흩어진 Lot과 장비, FDC 정보를 하나의 플랫폼에서 확인하고, 실시간 현황과 Summary Chart로 핵심 정보를 빠르게 파악합니다. 이어서 DOE 결과를 업데이트하고 조직과 공유해, 분석 방법과 최적 조건 탐색 로직을 조직의 자산으로 축적합니다.”

## 5. 장면별 구성 및 모션

### CUT 1 — 여러 시스템에 흩어진 현황 (0~4초)

**화면**
- 어두운 연구 환경에 여러 모니터와 정보 패널이 분산되어 있다.
- 패널은 Lot 현황, 장비 현황, FDC 현황을 상징한다.
- 상단 제목: `여러 시스템에 흩어진 Lot·장비·FDC 현황`
- 특정 시스템명이나 실제로 제공되지 않은 데이터 값은 넣지 않는다.

**나레이션**
“여러 시스템과 자료에 흩어진 Lot과 장비, FDC 정보를…”

**모션**
1. 어두운 연구 환경에서 모니터 몇 개가 순차적으로 켜진다.
2. Lot 현황 패널, 장비 현황 패널, FDC 현황 패널이 서로 다른 위치에서 0.3초 정도 간격을 두고 등장한다.
3. 패널마다 미세한 원근감과 깊이 차이를 주고, 카메라는 좌우로 천천히 이동하며 여러 화면을 훑는다.
4. 각 패널 안의 일반적인 표와 그래프는 아주 약하게 움직이되, 가짜 숫자나 읽을 수 있는 임의의 분석 결과는 강조하지 않는다.
5. 패널 사이의 간격을 유지해 정보가 분산된 상태를 보여준다.

**전환**
- 각 패널의 가장자리에서 얇은 골드 라인이 켜지고, 선들이 화면 중앙으로 향하며 CUT 2로 연결된다.

### CUT 2 — 하나의 웹 플랫폼에서 통합 조회 (4~8초)

**화면**
- 중앙에 Thinfilm Agent의 통합 플랫폼 화면이 나타난다.
- 화면에는 Lot 현황, 장비 현황, FDC 모니터링, DOE 관리로 이어지는 기능 영역을 간결하게 표현한다.
- 상단 제목: `하나의 웹 플랫폼에서 통합 조회`

**나레이션**
“…하나의 플랫폼에서 확인하고,”

**모션**
1. CUT 1의 분산된 패널에서 골드 라인이 중앙 플랫폼을 향해 이동한다.
2. 플랫폼 패널이 배경 깊은 곳에서 앞으로 다가오며 크기가 커지고, 화면 중앙에서 정면으로 정렬된다.
3. Lot·장비·FDC·DOE 기능 타일이 위에서 아래 또는 좌측에서 우측으로 차례로 나타난다.
4. 각 타일은 등장할 때 얇은 골드 테두리가 짧게 켜졌다가 안정된다.
5. 커서가 검색 영역에 잠깐 나타나고 검색 아이콘이 은은하게 빛나면서 조회 동작을 암시한다. 임의의 Lot ID나 조회 결과는 생성하지 않는다.
6. 카메라는 플랫폼을 향해 천천히 푸시인(push-in)한다.

**전환**
- 플랫폼 안의 현황 타일들이 각각 확장되며 CUT 3의 Summary Chart 화면으로 자연스럽게 이어진다.

### CUT 3 — 실시간 현황과 Summary Chart 시각화 (8~12초)

**화면**
- Lot Trend, Equipment Status, FDC Summary, DOE Result를 상징하는 시각화 패널을 보여준다.
- 상단 제목: `실시간 데이터와 시각화로 더 빠르게`
- 실제 화면이 제공되면 해당 화면을 사용한다. 실제 화면이 없다면 범용 차트로 표현한다.

**나레이션**
“실시간 현황과 Summary Chart로 핵심 정보를 빠르게 파악합니다.”

**모션**
1. Lot Trend 차트의 선이 왼쪽에서 오른쪽으로 그려진다.
2. Equipment Status는 원형 차트의 각 구간이 순차적으로 채워진다. 실제 상태별 수치가 없으면 범례·수치를 사실처럼 표시하지 않는다.
3. FDC Summary의 막대그래프가 왼쪽에서 오른쪽으로 차례로 올라온다.
4. DOE 결과 영역은 부드럽게 확대되며 시각화 화면이 나타난다. 실제 DOE 결과 데이터가 없으면 임의의 최적 조건 값이나 성능 수치를 넣지 않는다.
5. 각 패널을 동시에 과도하게 움직이지 말고, 0.5~0.8초 간격으로 순차 강조한다.
6. 카메라는 전체 대시보드에서 핵심 차트로 부드럽게 이동한 뒤 전체 화면으로 돌아온다.

**전환**
- DOE Result 패널 가장자리에 골드 라이트가 켜지고, 그 빛이 보고서/공유 화면으로 이동하며 CUT 4로 연결된다.

### CUT 4 — DOE 결과 업데이트 및 공유 (12~17초)

**화면**
- DOE 결과와 분석 보고서를 정리한 화면을 보여준다.
- 보고서가 업데이트되고 조직 내 공유가 이루어지는 흐름을 시각화한다.
- 상단 제목: `DOE 결과와 분석을 조직과 공유`
- 메일/알림 아이콘은 업데이트·공유를 상징하는 보조 요소로만 사용한다. 자동 메일 발송이 실제 기능으로 확인되지 않았다면 자동 발송을 단정하지 않는다.

**나레이션**
“DOE 결과를 업데이트하고 조직과 공유해,”

**모션**
1. DOE 결과 패널이 화면 중앙으로 이동해 크게 보인다.
2. 보고서 화면이 부드럽게 펼쳐지고, 차트와 요약 영역이 순차적으로 나타난다.
3. 업데이트 표시가 골드 색으로 짧게 강조된다.
4. 보고서에서 조직 공유를 상징하는 여러 사용자 아이콘으로 얇은 선이 이어진다.
5. 사용자 아이콘은 차례로 켜지며 공유 범위를 표현한다. 실제 협업 시스템의 구체적인 사용자나 부서 이름은 넣지 않는다.
6. 카메라는 보고서에서 공유 아이콘 방향으로 부드럽게 이동한다.

**전환**
- 공유 아이콘을 연결하는 선이 화면 중앙에서 하나의 골드 라인으로 모이며 CUT 5로 이어진다.

### CUT 5 — 업무 효율화와 조직 자산화 (17~23초)

**화면**
- 딥블랙 배경에 통합 플랫폼과 반도체 웨이퍼를 배치한다.
- 핵심 문구: `DOE 분석 효율화 · 최적 조건 탐색 지원`
- 보조 문구: `분석 방법과 최적 조건 탐색 로직을 조직의 자산으로`
- 확인되지 않은 시간 절감 수치나 개선율은 표시하지 않는다.

**나레이션**
“분석 방법과 최적 조건 탐색 로직을 조직의 자산으로 축적합니다.”

**모션**
1. 앞 장면의 골드 라인이 화면 중앙의 플랫폼/웨이퍼 주변을 따라 부드럽게 흐른다.
2. DOE 결과, 분석 방법, 최적 조건 탐색을 상징하는 세 개의 아이콘이 차례로 나타난다.
3. 아이콘이 골드 라인으로 연결되고, 하나의 정돈된 구조로 자리 잡는다.
4. 핵심 문구가 약한 블러에서 선명하게 전환되며 페이드 인한다.
5. 보조 문구는 0.3~0.5초 뒤 아래에서 살짝 올라오며 나타난다.
6. 배경의 웨이퍼는 천천히 회전하거나 표면을 골드 빛이 훑는다. 텍스트보다 시각 효과가 튀지 않게 한다.
7. 마지막 0.8~1초 동안 문구를 안정적으로 유지한 뒤 다음 과제로 자연스럽게 전환한다.

## 7. 음향 및 편집

- 배경음악은 차분하고 고급스러운 시네마틱 전자음악으로 한다.
- 패널 등장 시 작은 UI 톤, 골드 연결선 이동 시 부드러운 상승음, 차트 애니메이션 시 절제된 전자음을 사용한다.
- DOE 공유 장면에는 낮고 부드러운 알림음을 사용할 수 있으나, 과도한 메일 알림음은 피한다.
- 마지막 메시지 등장 시 은은한 저음과 짧은 반짝임 효과를 사용한다.
- 효과음이 나레이션을 가리지 않도록 믹싱한다.
- 장면 전환은 골드 빛의 흐름, 카메라 이동, 부드러운 페이드로 연결한다.

## 8. 필수 구현 및 금지 사항

### 필수 구현
- 5개 장면을 각각 독립된 영상 컷으로 재구성한다.
- 패널 등장·이동, 플랫폼 확대·정렬, 골드 연결선, 차트 애니메이션, 보고서 업데이트·공유 시각화, 웨이퍼 조명/카메라 이동을 구현한다.
- 나레이션은 장면 경계에서 부자연스럽게 끊기지 않도록 한다.
- 한글 문구와 기능명을 코드 또는 편집 도구로 정확하게 렌더링한다.
- 실제 플랫폼 화면이 제공되면 임의의 UI보다 실제 화면을 우선한다.

### 금지 사항
- 스토리보드 이미지 한 장을 그대로 정지 화면으로 사용하기
- 화면을 정지한 채 나레이션만 읽거나 자막만 교체하기
- 확정 시안과 무관한 디자인으로 변경하기
- 실제 근거가 없는 `약 4시간 → 1시간 이내` 등의 시간 절감 수치 또는 개선율을 표시하기
- 실제로 확인되지 않은 자동 알림, 최적 조건 산출 결과, 상세 DOE 수치, 이상 탐지 기능을 만들어 넣기
- 블루/네온 블루를 주조색으로 사용하기
