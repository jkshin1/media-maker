# R&D 공정 AI Fast Track — 서우석 TL C&C Working Board Agent 영상 제작 MD

> **기준 시안:** 사용자가 선택한 서우석 TL 과제 시안 1번.
> **핵심 방향:** 흩어진 회의 자료·이슈·관련 문서를 AI Agent로 찾아보고, 핵심 정보를 정리해 업무에 활용하는 흐름을 보여준다.
> **중요:** 이 MD의 장면별 모션을 실제 영상으로 구현한다. 스토리보드 이미지를 한 장 그대로 띄우거나, 정지 화면에 나레이션만 얹는 방식은 금지한다.

## 1. 과제 정보
- **과제명:** C&C Working Board Agent
- **담당:** 서우석 TL
- **핵심 메시지:** 흩어진 정보와 회의 자료를 AI Agent로 검색·정리해 C&C 협업과 의사결정을 지원
- **확인된 기능 방향:** 회의 자료·이슈 통합 조회, 관련 문서 및 지식 검색, 이슈 요약·핵심 정리, 업무 진행 현황 확인
- **영상 길이:** 약 20~25초
- **장면 수:** 5개
- **출력 사양:** 16:9, 1920×1080 Full HD, 30fps, H.264/AAC MP4

## 2. 디자인 규칙
- 기존 R&D 공정 AI Fast Track 공통 제작 규칙을 우선 적용한다.
- 딥블랙 배경, 골드·앰버 포인트 조명, 크림색/화이트 타이포그래피를 유지한다.
- 기준 색상: 배경 `#080808`, 딥 차콜 `#1A1A1F`, 골드 `#D4AF7C`, 라이트 골드 `#F5D6A6`, 앰버 `#FFB347`, 보조 텍스트 `#F2EEE7`.
- 앞선 두 과제와 색감은 통일하되, 화면 연출은 차별화한다. 데이터 패널을 하나의 대시보드로 합치는 장면을 반복하기보다 **자료 탐색 → 질문/검색 → 핵심 내용 정리 → 업무 활용**의 흐름을 중심으로 보여준다.
- 블루/네온 블루를 주조색으로 사용하지 않는다.
- 한글 텍스트는 코드 또는 편집 도구로 정확하게 렌더링한다. 이미지 생성 결과에 포함된 글자를 그대로 사용하지 않는다.
- 실제 과제 자료에서 확인되지 않은 자동 회의록 작성, 자동 액션 생성, 자동 알림, 진행률 수치 등은 확정 기능으로 표현하지 않는다. 실제 화면이 제공되지 않은 경우 추상적인 예시 UI로 표현한다.
- 시안의 예시 수치·날짜·담당자·상태는 영상에 사용하지 않는다.

## 3. 전체 나레이션
장면마다 문장을 기계적으로 끊지 않고, 한 문장이 다음 장면으로 자연스럽게 이어지도록 녹음·편집한다.

“회의 자료와 이슈, 관련 문서가 여러 곳에 흩어져 있어 필요한 정보를 찾는 데 시간이 걸립니다. C&C Working Board Agent를 통해 관련 자료와 지식을 검색하고, 핵심 이슈와 내용을 빠르게 파악합니다. 필요한 정보를 업무에 활용해 협업과 의사결정을 지원합니다.”

## 4. 장면별 구성 및 모션 지시

### CUT 1 — 흩어진 자료와 이슈 (0~4초)
**화면 목적:** 자료와 이슈가 여러 위치에 흩어져 있어 필요한 정보를 찾아야 하는 상황을 보여준다.

**화면 구성**
- 어두운 C&C 연구/협업 환경에 회의 자료, 이슈 목록, 보고서, 관련 문서 패널이 서로 떨어져 떠 있다.
- 화면 문구: `흩어진 자료와 이슈`
- 패널에는 문서·표·이슈 카드 형태를 사용하되, 실제로 확인되지 않은 문서명이나 상세 내용은 만들지 않는다.

**나레이션**
“회의 자료와 이슈, 관련 문서가 여러 곳에 흩어져 있어…”

**모션**
1. 검은 배경에서 여러 문서 패널의 윤곽이 차례로 켜진다.
2. 회의 자료, 이슈 목록, 보고서 패널이 화면 양옆과 뒤쪽에서 순차적으로 등장한다.
3. 패널마다 서로 다른 깊이와 각도를 주고, 약한 패럴랙스 효과를 적용한다.
4. 카메라는 좌우로 천천히 움직이며 자료 사이를 훑는다. 자료가 많아 복잡한 상황임을 보여주되, 화면이 어지럽게 흔들리지 않도록 한다.
5. 일부 패널은 살짝 앞으로 이동한 뒤 멈추고, 나머지는 배경에 남겨 깊이감을 만든다.
6. 텍스트는 짧은 제목만 선명하게 보여주고 가짜 문서 본문은 읽히지 않게 처리한다.

**전환**
- 화면 중앙에 검색창을 암시하는 골드 프레임이 켜지고, 주변 자료에서 빛이 검색창 쪽으로 흐르며 CUT 2로 이어진다.

### CUT 2 — 필요한 정보 찾기 (4~8초)
**화면 목적:** AI Agent를 통해 관련 자료와 지식을 검색하는 모습을 보여준다.

**화면 구성**
- 중앙에 `C&C Working Board Agent`를 상징하는 검색 인터페이스가 나타난다.
- 검색창과 간결한 검색 결과 카드가 보인다.
- 화면 문구: `필요한 정보를 빠르게 검색`
- 검색 결과는 관련 문서·회의 자료·지식 자료의 카드 형태로 표현한다. 구체적인 답변이나 기능은 실제 자료에 없는 내용으로 단정하지 않는다.

**나레이션**
“…필요한 정보를 찾는 데 시간이 걸립니다. C&C Working Board Agent를 통해 관련 자료와 지식을 검색하고,”

**모션**
1. CUT 1의 문서 패널에서 얇은 골드 라인이 검색창으로 모인다.
2. 검색창이 화면 중앙에서 부드럽게 확대되며 나타난다.
3. 검색창에 커서가 깜박이고, 검색어가 입력되는 듯한 짧은 타이핑 모션을 준다. 실제 사용자 발화나 검색어가 제공되지 않았다면 구체적인 질의 문장은 표시하지 않는다.
4. 검색 결과 카드가 한 장씩 위에서 아래로 등장한다.
5. 카드가 나타날 때 문서 아이콘과 골드 테두리가 짧게 강조된다.
6. 카메라는 검색창에서 결과 카드로 천천히 이동해 원하는 자료를 찾는 흐름을 보여준다.

**전환**
- 검색 결과 카드들이 화면 중앙에 정돈되며 CUT 3의 핵심 내용 정리 화면으로 연결된다.

### CUT 3 — 핵심 내용 정리 (8~13초)
**화면 목적:** 검색한 자료와 이슈에서 필요한 핵심 내용을 파악하기 쉽게 정리하는 흐름을 보여준다.

**화면 구성**
- 회의 자료와 이슈 카드가 정돈된 요약 화면으로 전환된다.
- 화면 문구: `핵심 이슈와 내용 정리`
- 시각 요소는 `핵심 내용`, `관련 이슈`, `참고 자료` 같은 일반적인 구분으로 구성할 수 있다. 실제 자료에서 확인되지 않은 자동 회의록 작성이나 액션 아이템 자동 생성은 표현하지 않는다.

**나레이션**
“핵심 이슈와 내용을 빠르게 파악합니다.”

**모션**
1. CUT 2의 검색 결과 카드가 화면 중앙으로 모여 일정한 간격으로 정렬된다.
2. 문서의 일부 영역이 골드 테두리로 강조되며 핵심 정보를 살펴보는 느낌을 준다.
3. 여러 카드에서 핵심 키워드를 상징하는 짧은 하이라이트가 차례로 나타난다.
4. 관련 문서 아이콘이 얇은 골드 선으로 연결되어 정보 간 관계를 보여준다.
5. 카메라는 전체 요약 화면에서 강조 영역으로 부드럽게 푸시인한 뒤, 화면 전체를 다시 보여준다.
6. 문서 내용은 실제 제공 자료를 사용하거나, 자료가 없으면 읽을 수 없는 추상 텍스트로 처리한다.

**전환**
- 강조된 키워드에서 골드 라인이 뻗어 나와 CUT 4의 업무 현황 화면으로 이어진다.

### CUT 4 — 업무 진행 현황 확인 (13~18초)
**화면 목적:** 검색·정리된 정보가 업무 진행 상황을 파악하는 데 활용될 수 있음을 보여준다.

**화면 구성**
- 이슈 카드와 관련 자료가 간결한 현황 목록으로 정돈된다.
- 화면 문구: `업무 진행 현황 확인`
- 실제 과제 자료에서 진행 상태 확인 기능이 확인되는 범위 내에서만 표현한다.
- 진행률, 상태별 건수, 담당자, 마감일 등 검증되지 않은 구체적인 수치·개인정보는 표시하지 않는다.

**나레이션**
“필요한 정보를 업무에 활용해…”

**모션**
1. CUT 3의 관련 이슈 카드가 화면 아래쪽으로 이동해 현황 목록을 형성한다.
2. 목록의 항목이 위에서 아래로 순차적으로 나타난다.
3. 한 항목이 선택되면 관련 자료 카드가 옆에 부드럽게 펼쳐진다.
4. 상태 표현이 필요하다면 숫자 대신 중립적인 아이콘과 간단한 상태 표시를 사용한다.
5. 카메라는 목록에서 관련 자료로 천천히 이동해 정보가 업무와 연결되는 모습을 보여준다.
6. 실제 기능이 불명확한 알림 팝업, 자동 메시지, 자동 담당자 지정은 넣지 않는다.

**전환**
- 현황 목록의 골드 라인이 화면 중앙으로 모이며 CUT 5의 마무리 메시지로 연결된다.

### CUT 5 — 협업과 의사결정 지원 (18~23초)
**화면 목적:** 필요한 정보를 찾고 정리하는 과정이 협업과 의사결정을 지원한다는 메시지로 마무리한다.

**화면 구성**
- 여러 문서와 이슈를 확인하는 협업 환경을 배경으로 사용한다.
- 화면 중앙 문구: `더 빠르고 효율적인 C&C 협업`
- 보조 문구: `필요한 정보를 찾아 업무와 의사결정에 활용`
- 과제에 없는 정량 성과나 자동화 기능은 추가하지 않는다.

**나레이션**
“협업과 의사결정을 지원합니다.”

**모션**
1. 앞 장면의 문서·이슈 카드가 화면 중앙을 중심으로 안정적으로 정렬된다.
2. 자료와 이슈를 연결하는 골드 선이 하나의 명료한 흐름을 만든다.
3. 배경에 협업 중인 연구원들의 실루엣 또는 어두운 회의 공간을 은은하게 드러낸다.
4. 메인 문구가 부드럽게 페이드 인하고, 0.3~0.5초 뒤 보조 문구가 아래에서 살짝 올라오며 나타난다.
5. 카메라는 화면 중앙 메시지로 천천히 이동한다.
6. 마지막 0.8~1초는 문구를 읽을 수 있도록 안정적으로 유지한 후 다음 영상으로 부드럽게 전환한다.

## 6. 음향 및 편집
- 배경음악은 차분하고 고급스러운 시네마틱 전자음악으로 한다.
- CUT 1은 여러 패널이 등장할 때 작은 UI 톤을 사용한다.
- CUT 2는 검색창 활성화와 결과 카드 등장에 부드러운 전자음을 사용한다.
- CUT 3은 하이라이트와 문서 연결 시 짧고 절제된 효과음을 사용한다.
- CUT 4는 현황 목록이 정리될 때 낮고 부드러운 톤을 사용한다.
- CUT 5는 메인 문구 등장 시 은은한 저음과 골드 반짝임 효과를 사용한다.
- 효과음이 나레이션을 가리지 않도록 한다.
- 급격한 플래시, 글리치, 흔들림, 과도한 레이저 효과는 금지한다.
