## 1. Claude에게 전달할 핵심 지시

첨부된 공통 제작 규칙, 오프닝 MD, 서머리 MD 4개, 개별 과제 MD 12개, 엔딩 MD를 모두 확인한 뒤 **하나의 연속된 최종 영상**으로 편집·렌더링해 주세요.

### 반드시 지킬 사항

1. **각 MD는 해당 장면의 제작 기준 문서입니다.** 장면 구성, 나레이션, 과제명, 담당자명, 성과 수치, 디자인 지시를 임의로 바꾸지 마세요.
2. 스토리보드 이미지를 정지 화면으로 길게 보여주는 방식은 금지합니다. MD에 적힌 카드 이동, 카메라 이동, 데이터·이미지 애니메이션, 그래프 표시, 빛의 흐름, 전환 등을 실제 모션으로 구현하세요.
3. 한국어 문구는 이미지 생성 결과에 의존하지 말고, 영상 편집 단계에서 정확한 텍스트 레이어로 구현하세요.
4. 각 개별 과제 영상의 시작에는 **과제명과 담당자명 타이틀 화면**을 넣습니다. 공통 제작 규칙과 각 과제 MD에 명시된 표기법을 따르세요.
5. 검정·차콜 배경과 골드·앰버 포인트를 전체 영상의 공통 디자인으로 유지합니다. 임의로 파란 네온 중심 디자인이나 전혀 다른 템플릿을 추가하지 마세요.
6. 공통 디자인을 유지하되, 각 과제의 실제 기능이 드러나도록 이미지와 화면 구성은 과제별로 구분하세요. 같은 연구원 이미지나 웨이퍼 이미지를 반복 복제하지 마세요.
7. 과제에서 확인되지 않은 기능, 가상 성과 수치, 원인 진단, 자동 판정 등을 추가하지 마세요. 수치는 해당 과제 MD에 적힌 검수 지시를 따르세요.
8. 나레이션은 MD의 확정 원고를 사용하고, 장면 길이와 맞춰 배치하세요. 나레이션이 없는 장면에는 새 나레이션을 추가하지 마세요.
9. 최종 영상뿐 아니라 실행 가능한 소스 코드와 실행 방법도 함께 제공하세요.
10. 최종 MP4는 처음부터 끝까지 재생해 영상·음성·자막·전환·텍스트 잘림 여부를 검수한 뒤 제출하세요.

## 4. 공통 디자인 및 화면 규칙

### 화면 규격
- 16:9 가로형
- 권장 해상도: 1920 × 1080
- 권장 프레임레이트: 30 fps

### 색상·분위기
- Black: `#080808`
- Charcoal: `#1A1A1F`
- Gold: `#D4AF7C`
- Light Gold: `#F5D6A6`
- Amber: `#FFB347`
- Cream: `#F2EEE7`

전체적으로 고급스럽고 미래적인 반도체 R&D 분위기를 유지합니다. 화면은 검정·골드 중심으로 구성하고, 파란색은 실제 데이터 화면의 그래프나 UI에 필요한 범위에서만 보조적으로 사용합니다.

### 텍스트
- 제목, 과제명, 담당자명, 나레이션 자막은 편집 가능한 텍스트 레이어로 구현합니다.
- 한글이 깨지거나 임의의 글자로 바뀌지 않도록 폰트와 줄바꿈을 확인합니다.
- 각 개별 과제 영상의 시작에는 과제명과 담당자명이 들어간 타이틀 화면을 배치합니다.
- 각 과제의 기존 시안에 있는 상단 컷 제목과 하단 나레이션을 유지합니다.
- 나레이션 자막을 넣는 경우 실제 나레이션과 정확히 일치시킵니다.

### 모션
- 카드 등장·정렬, 카메라 푸시인·트래킹, 패널 전환, 데이터 흐름, 이미지 계측선, 그래프 애니메이션, 골드 라이트 등을 장면 목적에 맞게 사용합니다.
- 같은 전환 효과를 모든 장면에 기계적으로 반복하지 않습니다.
- 단순히 정지 이미지를 확대하거나 좌우로 움직이는 것만으로 모션을 대체하지 않습니다.
- 각 장면의 기능을 이해할 수 있도록 핵심 UI 모션을 우선 구현합니다.

### 사운드
- 배경음악은 전체적으로 통일하되, 장면별 UI 사운드와 강조음을 절제해서 사용합니다.
- 나레이션을 가리지 않도록 배경음악 볼륨을 조정합니다.
- 장면 전환 시 음악이 갑자기 끊기거나 음량이 튀지 않도록 믹싱합니다.

## 5. 나레이션 및 장면 길이 원칙

- 나레이션 원고는 각 MD에 적힌 문장을 사용합니다.
- 문장 표현을 임의로 바꾸거나 비슷한 메시지를 중복해서 읽지 않습니다.
- 나레이션이 없는 장면에는 새 원고를 추가하지 않습니다.
- 문장이 다음 컷과 연결되는 경우 쉼표와 호흡을 유지합니다.
- 긴 과제명이나 담당자명이 읽히는 장면은 텍스트가 충분히 보이도록 유지합니다.
- 각 개별 과제의 실제 길이는 해당 과제 MD의 지시를 우선합니다.
- 전체 영상은 장면 사이에 불필요한 검은 화면이나 긴 공백 없이 자연스럽게 이어 붙입니다.

### 엔딩 나레이션 주의
- 엔딩 MD의 최신 원고를 따릅니다.
- “그중에서도 주목할 두 과제를 소개합니다”와 “이제 두 개의 우수 과제를 만나봅니다”를 연속해서 중복 사용하지 않습니다.
- 우수 과제 카드가 나오는 마지막 장면은 **나레이션 없이 화면과 배경음악으로만** 소개합니다.
- 카드의 과제명과 담당자명이 읽히도록 화면을 유지하고, 필요하면 엔딩 길이를 연장합니다.

## 6. 기술적 제작 지침

1. 모든 장면을 개별 컴포지션 또는 모듈로 만들어 수정하기 쉽게 구성합니다.
2. 공통 색상, 글꼴, 카드 테두리, 전환 효과는 재사용 가능한 스타일로 관리합니다.
3. 과제명·담당자명·컷 제목·나레이션은 이미지에 굽지 말고 편집 가능한 텍스트로 구현합니다.
4. 음성 파일과 배경음악은 별도 트랙으로 관리합니다.
5. 장면별 길이는 나레이션 길이와 실제 모션을 기준으로 조정합니다. 전체 시간을 맞추기 위해 나레이션을 지나치게 빠르게 재생하지 않습니다.
6. 출력 해상도와 프레임레이트를 통일하고, 모든 클립의 화면 비율·색상·음량을 점검합니다.
7. 전환 과정에서 프레임이 검게 끊기거나, 카드가 겹치거나, 텍스트가 화면 밖으로 나가지 않도록 확인합니다.
8. 원본 시안의 텍스트가 이미지 생성 과정에서 왜곡되어 있으면 해당 텍스트를 그대로 사용하지 말고 정확한 텍스트 레이어로 재작성합니다.
9. 승인된 시안의 핵심 디자인과 장면 순서는 바꾸지 않습니다. 기술적으로 구현이 어려운 경우 임의로 대체하지 말고, 해당 부분을 식별해 보고합니다.
