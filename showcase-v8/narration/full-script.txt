R&D 현업에 AI를 더합니다. 더 나은 R&D 공정을 위한 변화가 시작됩니다. 현장의 경험과 AI 기술이 만나 새로운 해법을 만들어갑니다. 현업의 다양한 과제를 해결하기 위한 도전입니다. 현업의 문제를 AI로 해결하는 R&D 공정 AI Fast Track. 서로 다른 현업의 고민에서 12개의 AI Agent 과제가 시작됐습니다. 현업의 고민을 해결하기 위해 개발한 다양한 AI Agent를 살펴봅니다. 업무 효율을 높이고, 데이터 기반의 의사결정과 새로운 분석을 지원합니다. 지금부터 12개의 AI Agent 과제를 소개합니다.

여러 도구에서 필터를 설정하고, 담당자의 경험으로 열화 원인을 분석했습니다. Lot ID를 입력하면 Map과 Trend, K-param을 함께 조회합니다. 표준 진단 기준을 적용해 원인 분석과 솔루션 검토를 지원합니다. 기존 15분에서 1시간이던 분석은, 자료 기준 건당 수분으로 줄었습니다. 반복 조회와 설정을 줄이고, 분석 근거를 한 화면에서 확인합니다.

매일 여러 시스템의 장비 이슈와 PM 계획을 모아, 엑셀 정리부터 메일 발송까지 반복했습니다. Agent가 장비 이력과 PM 계획을 조회합니다. 내용을 요약해 오전 6시에 표준 HTML 보고 메일을 자동 발송합니다. 자료 기준, 일일 보고 작성은 20분에서 0분으로, 연간 약 122시간을 절감했습니다. 담당자는 메일 확인과 검토, 장비 대응에 집중합니다.

HyDisk와 Cube에서 과거 자료를 찾고 전문가에게 물어야 해, 지식이 특정 담당자에게 편중됐습니다. 평가 목적을 입력하면 내부 지식 아카이브를 검색합니다. 관련 Recipe와 근거 자료를 함께 제안합니다. 자료 탐색과 구두 문의 의존을 줄여 평가 계획 수립을 지원합니다. 전문가 지식을 축적해, 담당자가 바뀌어도 활용할 수 있는 기반을 마련합니다.

TEM 이미지를 돌리고 측정선을 그어 값을 기록하면서, 측정자와 이미지 상태에 따른 편차가 생겼습니다. 이미지 기울기와 측정 위치를 분석합니다. 측정값과 좌표, 측정선 오버레이를 자동 생성하고 결과와 이력을 저장합니다. 자료 기준, 이미지당 측정 시간은 5분에서 6초로 줄었습니다. 담당자는 결과 검토와 예외 확인에 집중하며, 새 이미지의 누락·오류 보완과 사람의 최종 검증은 계속 필요합니다.

자료가 어느 파일에 있는지 찾고, 여러 표를 열어 비교와 복사, 요약을 반복했습니다. 데이터를 Working Board에 등록합니다. 자연어 질문으로 필요한 정보를 추출하고 여러 데이터를 교차 분석합니다. 조회 창구를 단일화해 파일 탐색과 반복 취합 부담을 줄입니다. 분석 자료와 도메인 지식을 함께 관리할 수 있는 기반을 마련합니다.

Spec out이 생기면 여러 공정의 이력을 조사하고 데이터를 가공해, 연계공정의 이상 여부를 확인했습니다. Lot ID와 메인 공정을 입력해 데이터 수집과 통합을 연결합니다. 상관관계와 이상치를 분석하고, 원인공정 후보 랭킹과 리포트를 생성합니다. 자료에는 분석 시간이 70퍼센트 이상 단축된 것으로 기재돼 있습니다. 분석 절차와 기준을 일관되게 적용하며, 원인공정은 확정 원인이 아닌 후보로 검토합니다.

Lot과 장비, FDC를 따로 조회하고, 개인이 보유한 DOE 결과를 공유하기 어려웠습니다. 웹 플랫폼에서 현황과 모니터링 Trend를 통합 조회합니다. 구성원이 DOE 평가 결과를 함께 확인합니다. 시스템 이동과 데이터 가공 부담을 줄입니다. 개인의 평가 결과와 분석 노하우를 조직 안에서 공유합니다.

경비를 엑셀로 집계하고 장비 이력을 개별 확인해, 일부 항목을 경험에 따라 분석했습니다. 경비와 장비 이력을 연결하고 22개 판단 지표를 추가했습니다. 비용 증가 원인과 절감 검토 후보를 분석하고 실행 가능성을 함께 살핍니다. 자료에는 분석 시간 80퍼센트 이상 단축으로 기재됐지만, 지표와 결과의 실효성은 검증 중입니다. 비용 금액에 머물지 않고 판단 근거를 넓히되, 절감 검토 후보와 확정 절감 실적을 구분합니다.

Lot 하나를 해석하려고 공정 이력과 Inline, 장비와 FDC, 연계공정 정보를 각각 조사하고 정리했습니다. 앱에서 Lot과 장비 이력, Inline 데이터를 조회하고 추출합니다. Lot 간 공정 수순과 장비, Recipe 차이를 비교합니다. 자료 기준, Lot 한 건 분석은 약 2시간 40분에서 20분 이내로 줄었습니다. 공정 결과 해석에 집중하며, 자동 보고와 고도화된 연구 지원 Agent는 추가 개발 계획입니다.

Smart Factory별 조회와 엑셀 가공·시각화에 주당 한 시간 이상을 쓰고 있었습니다. 필요한 공정 데이터를 자연어로 조회합니다. Wafer Map과 그래프로 시각화해 수동 가공을 간소화합니다. 자료에는 업무 시간이 40퍼센트 이상 단축된 것으로 기재돼 있습니다. 공정과 장비 간 협업을 돕고, 챗봇 자동 알림과 Reporting은 향후 계획입니다.

다섯 개 이상 시스템에서 Lot과 장비, TEM을 확인하고 보고와 주말 근무자 정보를 따로 모았습니다. 하나의 앱에서 Lot과 장비 상태, TEM 쿼터와 의뢰 현황을 통합 조회합니다. Daily와 Weekly Report, 주말 근무자 안내를 자동화합니다. 자료에는 업무 시간이 90퍼센트 이상 단축된 것으로 기재돼 있습니다. 반복 조회와 취합, 보고 부담을 줄이고 축적된 데이터를 분석에 활용합니다.

대량의 데이터를 내려받아 가공하고 오계측을 육안 검토하면서, 시간과 판정 편차가 발생했습니다. 계측 데이터의 수집과 전처리, 적재를 자동화합니다. 이미지 기반 오계측 후보 탐지와 대시보드 자연어 분석을 제공합니다. 자료상 수집 시간은 1200초에서 75초로, 단일 층 검증의 리뷰 대상은 317건에서 19건으로 줄었습니다. 담당자의 검토 범위를 줄이며, PROvision 확장은 향후 계획입니다.
