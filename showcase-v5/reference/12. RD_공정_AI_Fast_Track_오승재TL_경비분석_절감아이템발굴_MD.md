## 1. 제작 목표

기존 시안의 5컷 구성과 핵심 메시지를 유지한다. 각 컷 상단에는 제목을, 하단에는 나레이션을 배치한다. 나레이션은 기존 업무에서 AI Agent의 분석, 절감 가능 항목 도출, 검토 결과 제공, 업무 효과로 자연스럽게 이어지도록 한다.

## 4. 컷별 제작 지시

### CUT 1 — 흩어진 경비 데이터를 통합

**나레이션**
> 경비 실적과 장비 이력 등 필요한 데이터가 여러 곳에 분산되어 있습니다.

**화면 구성**
- 경비 실적, 장비 이력, 구매·계약 정보, 유지보수 이력, 기타 자료가 서로 다른 화면에 분산된 모습.
- 연구원이 여러 화면을 확인하는 기존 업무 상황을 표현한다.
- 자료명은 시안에 있는 항목을 기준으로 정확하게 표기한다.
- 구체적인 금액이나 업체명 등 원본 자료에 없는 정보를 임의로 넣지 않는다.

**카메라·모션**
- 여러 데이터 화면 사이를 천천히 트래킹한다.
- 화면별로 경비 실적, 장비 이력, 구매·계약 정보 등이 차례로 강조된다.
- 데이터 카드들이 다음 컷의 AI Agent 화면 방향으로 이동하며 전환된다.

**상단 제목:** `흩어진 경비 데이터를 통합`

### CUT 2 — AI Agent가 데이터 수집·분석

**나레이션**
> AI Agent가 다양한 데이터를 자동으로 수집하고 분석합니다.

**화면 구성**
- 경비 분석 AI Agent 화면을 중심으로 구성한다.
- 경비 데이터 수집, 장비 이력 수집, 구매·계약 정보, 유지보수 이력, 데이터 분석 및 판단 지표 생성 항목을 보여준다.
- 여러 데이터가 Agent 화면으로 들어와 통합되는 흐름을 표현한다.
- AI 캐릭터를 사용하더라도 장식 요소로 제한하고, 화면의 핵심은 실제 데이터 수집·분석 기능이 되게 한다.

**카메라·모션**
- Agent 화면으로 부드럽게 푸시인한다.
- 데이터 항목이 순차적으로 활성화되고, 골드 연결선이 데이터 수집 흐름을 보여준다.
- 분석이 진행되면서 결과 패널이 화면에 나타난다.

**상단 제목:** `AI Agent가 데이터 수집·분석`

### CUT 3 — 절감 가능 항목과 인사이트 도출

**나레이션**
> 분석 결과를 기반으로 절감 가능 항목과 주요 인사이트를 제시합니다.

**화면 구성**
- 경비 분석 결과 패널을 보여준다.
- 시안의 경비 실적, 장비 이력, 분석 시간, 주요 절감 아이템, 경비 트렌드 분석 영역을 참고한다.
- 절감 가능 항목과 기대 효과를 보여주되, 금액·비율은 승인된 원본 자료에서 확인된 값만 사용한다.
- 예시로 보이는 절감액·절감률을 검증 없이 실제 결과처럼 사용하지 않는다.

**카메라·모션**
- 주요 지표 카드가 순차적으로 등장한다.
- 경비 트렌드 그래프가 선과 막대가 그려지는 방식으로 나타난다.
- 절감 가능 항목 리스트가 순서대로 강조된다.

**상단 제목:** `절감 가능 항목과 인사이트 도출`

### CUT 4 — 검토 결과까지 한눈에 제공

**나레이션**
> 검토 중인 항목과 제외 항목까지 포함해 전체 결과를 확인할 수 있습니다.

**화면 구성**
- 검토 결과 화면에 전체 제안, 검토 중, 제외 항목이 구분되어 나타난다.
- 항목별 주요 내용과 상태를 표로 보여준다.
- 결과 분포 시각화는 실제 자료에 포함된 경우에만 표시하고, 수치나 비율을 임의로 만들지 않는다.
- 검토 중 항목과 제외 항목도 결과에 포함된다는 점을 명확하게 표현한다.

**카메라·모션**
- 전체 제안, 검토 중, 제외 항목 탭이 순서대로 활성화된다.
- 결과표의 항목과 상태 태그가 차례로 강조된다.
- 필요 시 결과 분포 차트가 부드럽게 나타난다.

**상단 제목:** `검토 결과까지 한눈에 제공`

### CUT 5 — 더 효율적인 예산 운영 지원

**나레이션**
> 분석 시간을 80% 이상 줄이고 더 효율적인 예산 운영을 지원합니다.

**화면 구성**
- 연구원이 정리된 분석 결과를 확인하는 모습.
- 분석 시간 단축, 경비 실적, 장비 이력, 절감 기회 조기 발굴, 효율적인 예산 운영 지원을 핵심 효과로 표현한다.
- `분석 시간 80% 이상 단축`, `경비 실적 14,000건 이상`, `장비 이력 18,000건 이상`은 사용자가 제공한 기존 시안에 표시된 수치다. 최종 영상에 넣기 전에 승인된 원본 자료와 일치하는지 확인한다.
- 수치가 확인되지 않으면 해당 수치는 제거하고 효과 문구만 사용한다.

**카메라·모션**
- 핵심 효과 카드가 순차적으로 나타난다.
- 분석 시간 단축 지표와 경비·장비 데이터 규모가 차례로 강조된다.
- 마지막에는 연구 환경 또는 분석 결과 화면을 담은 안정적인 구도로 마무리한다.
- 다음 과제로 자연스럽게 연결할 수 있도록 짧게 유지한다.

**상단 제목:** `더 효율적인 예산 운영 지원`

- 승인된 나레이션을 임의로 늘리거나 반복하지 않는다.
