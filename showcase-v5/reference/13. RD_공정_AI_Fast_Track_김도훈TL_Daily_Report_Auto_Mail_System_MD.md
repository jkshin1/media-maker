# 장비 Daily Report Auto Mail System
## 김도훈 TL 과제 영상 제작 MD

> 제작 기준: 사용자가 제공한 기존 5컷 스토리보드 이미지  
> 담당: 김도훈 TL  
> 화면 비율: 16:9  
> 중요: 기존 시안의 5컷 구성과 기능 흐름을 유지한다. 확인되지 않은 기능이나 성과 수치는 임의로 추가하지 않는다.

---

## 1. 제작 목표

장비 데이터를 확인하고 보고서를 작성해 메일로 전달하던 반복 업무를, AI Agent가 필요한 장비 데이터를 자동으로 수집·분석하고 HTML 형식의 보고서를 생성한 뒤 지정된 담당자에게 메일로 발송하는 흐름으로 보여준다.

기존 시안의 5컷 구성과 핵심 메시지를 유지한다. 각 컷 상단에는 장면 제목, 하단에는 나레이션을 배치한다. 나레이션은 기존 반복 업무에서 자동 수집·분석, HTML 보고서 생성, 메일 발송, 업무 효율 향상으로 이어지도록 한다.

## 2. 공통 제작 규칙

함께 제공된 `RD_AI_Fast_Track_공통_제작_규칙_타이틀화면추가.md`를 준수한다.

- 화면 비율: 16:9 가로형
- 권장 해상도: 1920 × 1080
- 권장 프레임레이트: 30 fps
- 색상: 검정·차콜 배경, 골드·앰버 포인트
- 기본 팔레트: `#080808`, `#1A1A1F`, `#D4AF7C`, `#F5D6A6`, `#FFB347`, `#F2EEE7`
- 기존 시안의 5컷 구조, 컷 제목, 핵심 기능, 나레이션 흐름을 임의로 변경하지 않는다.
- 스토리보드 이미지 전체를 정지 화면으로 사용하지 않는다. 각 컷을 독립된 영상 장면으로 제작한다.
- 카메라 이동, 데이터 수집 애니메이션, HTML 보고서 구성, 메일 발송 화면 전환을 실제로 구현한다.
- 한국어 문구는 편집 단계에서 정확한 텍스트 레이어로 삽입한다.
- 실제 자료에서 확인되지 않은 기능·수치·보고서 지표를 임의로 만들지 않는다.
- 최종 결과물은 MP4, 실행 가능한 소스 코드, 실행 방법 안내를 포함한다.

본편 시작 전에 별도 타이틀 화면을 약 2–3초 표시한다.

**과제명:** `장비 Daily Report Auto Mail System`  
**담당자:** `김도훈 TL`

- 검정 배경과 골드 포인트를 사용한다.
- 과제명을 가장 크게, 담당자명을 아래에 배치한다.
- 타이틀 화면과 본편 CUT 1은 별도 장면으로 제작한다.
- 타이틀에서 본편으로 짧고 자연스럽게 전환한다.
- `SUMMARY` 또는 서머리 번호를 표시하지 않는다.

**전체 순서:** 과제명·담당자 타이틀(2–3초) → 5컷 본편 → 본편 마무리

## 4. 컷별 제작 지시

권장 본편 길이: 약 30–35초. 타이틀 화면은 별도 2–3초로 구성한다.

### CUT 1 — 반복되는 보고서 작업

**나레이션**
> 매일 장비 데이터를 확인하고 보고서를 작성해 메일로 전달하던 업무.

**화면 구성**
- 여러 장비 데이터 화면과 보고서 작성 화면을 함께 보여준다.
- 연구원이 데이터를 확인하고 정리한 뒤 보고서 작성과 메일 전달을 수행하는 기존 업무 흐름을 표현한다.
- 장비 데이터 확인, 데이터 정리, 보고서 작성, 메일 발송을 시각적으로 구분한다.
- 보고서 작성에 소요되는 구체적인 시간이나 일일 절감 시간은 표시하지 않는다.

**카메라·모션**
- 장비 데이터 화면에서 보고서 작성 화면으로 천천히 이동한다.
- 확인·정리·작성·전달 단계가 순차적으로 강조된다.
- 마지막에 데이터 화면들이 다음 컷의 AI Agent 수집 화면으로 이어진다.

**상단 제목:** `반복되는 보고서 작업`

---

### CUT 2 — 데이터를 자동으로 수집

**나레이션**
> 이제 AI Agent가 필요한 장비 데이터를 자동으로 수집합니다.

**화면 구성**
- SmartMES, GMS, IPA, Datalake 등 시안에 표시된 데이터 소스가 나타난다.
- 각 데이터 소스에서 AI Agent 방향으로 정보가 연결되는 흐름을 보여준다.
- 시안의 시스템 명칭을 정확하게 표기하고, 실제 연계 여부가 확인되지 않은 시스템은 임의로 추가하지 않는다.
- AI Agent는 데이터 수집과 분석을 지원하는 요소로 표현한다.

**카메라·모션**
- 데이터 소스가 순서대로 활성화된다.
- 골드 연결선이 각 소스에서 AI Agent로 이동한다.
- AI Agent 화면에 수집 완료 상태가 나타난 뒤 CUT 3의 보고서 화면으로 연결된다.

**상단 제목:** `데이터를 자동으로 수집`

---

### CUT 3 — HTML 보고서 자동 생성

**나레이션**
> 분석 결과를 바탕으로 HTML 형식의 보고서를 자동으로 생성합니다.

**화면 구성**
- HTML 형식의 장비 Daily Report가 구성되는 화면을 보여준다.
- 주요 지표 요약, 장비 현황, 데이터 그래프, 이슈 요약 등은 실제 과제 보고서에 포함된 항목만 사용한다.
- 시안에 있는 가동률, 생산량, 이상 건수 등 구체적인 예시 값은 승인된 원본 자료에서 확인된 경우에만 표시한다. 그렇지 않으면 숫자 없는 레이아웃이나 검증된 실제 값으로 대체한다.
- 이상 패턴을 자동 탐지하거나 원인을 진단하는 기능이 있는 것처럼 연출하지 않는다.

**카메라·모션**
- 빈 보고서 레이아웃에 제목, 요약 영역, 그래프, 표가 순서대로 구성된다.
- 그래프 선과 막대는 자연스럽게 그려지는 모션을 적용한다.
- 최종 HTML 보고서가 완성되면 화면을 짧게 유지한 뒤 CUT 4로 전환한다.

**상단 제목:** `HTML 보고서 자동 생성`

---

### CUT 4 — 담당자에게 자동 발송

**나레이션**
> 완성된 보고서를 지정된 담당자에게 자동으로 메일 발송합니다.

**화면 구성**
- 메일 발송 화면을 보여준다.
- 수신 대상, 제목, 본문, HTML 보고서 첨부가 정리되어 있는 모습을 표현한다.
- 실제 수신자 이메일 주소나 민감한 정보는 표시하지 않는다.
- 메일 발송 기능을 보여주되, 별도의 알림이나 후속 조치 기능은 추가하지 않는다.

**카메라·모션**
- 메일 제목과 첨부 보고서가 순차적으로 나타난다.
- 발송 버튼이 눌리는 동작 후 발송 완료 상태로 전환한다.
- 메일이 전달되는 짧은 골드 라인 모션으로 CUT 5에 연결한다.

**상단 제목:** `담당자에게 자동 발송`

---

### CUT 5 — 더 중요한 일에 집중

**나레이션**
> 반복 업무는 줄이고, 더 나은 의사결정을 지원합니다.

**화면 구성**
- 자동 생성된 보고서를 확인하는 연구원과 정돈된 업무 환경을 보여준다.
- 반복적인 데이터 확인·보고서 작성에서 보고서 검토와 업무 판단으로 집중점이 이동하는 변화를 표현한다.
- 시안의 효과 메시지인 반복 업무 감소, 보고서 작성 시간 절감, 더 나은 의사결정 지원을 활용한다.
- 구체적인 시간 절감 수치나 별도 성과 지표는 공식 자료에서 확인되지 않으면 넣지 않는다.

**카메라·모션**
- 완성된 보고서 화면에서 연구원으로 부드럽게 포커스를 이동한다.
- 배경 장비와 데이터 화면은 미세하게 움직이며 살아 있는 장면을 유지한다.
- 마지막에 골드 조명이 짧게 강조되고 다음 과제로 자연스럽게 연결된다.

**상단 제목:** `더 중요한 일에 집중`

- CUT 3: 보고서 섹션과 그래프가 구성될 때 가벼운 상승음

- 모든 컷에 같은 페이드만 반복하지 말고 트래킹, 푸시인, 패널 전환, 보고서 생성 애니메이션을 조합한다.

## 7. 정확성 및 금지사항

- 기존 시안의 5컷 구성과 기능 흐름을 유지한다.
- `SmartMES`, `GMS`, `IPA`, `Datalake`, `HTML 보고서`, `메일 발송` 등 용어를 정확하게 표기한다.
- 장비 데이터 수집·분석, HTML 보고서 자동 생성, 지정 담당자에게 메일 발송 범위 안에서 표현한다.
- 이상 패턴 자동 탐지, 원인 진단, 자동 조치, 자동 설비 제어 기능을 임의로 추가하지 않는다.
- 가동률, 생산량, 이상 건수, 날짜, 장비 ID 등 화면 속 수치는 공식 자료에서 확인된 경우에만 사용한다.
- 구체적인 시간 절감 수치를 임의로 추가하지 않는다.
- 시작 타이틀에 과제명과 `김도훈 TL`을 2–3초 표시한다.
- 각 컷의 상단 제목과 하단 나레이션을 유지한다.
- 정지 화면 슬라이드쇼가 아닌 실제 모션 영상으로 제작한다.
