# R&D 공정 AI Fast Track 엔딩 영상 제작 MD
## 성과 종합 → 우수 과제 소개

> 기준 시안: 사용자가 승인한 6장면 엔딩 스토리보드  
> 화면 비율: 16:9  
> 전체 길이: 약 12초  
> 디자인: 기존 오프닝·서머리와 동일한 검정·골드 시네마틱 스타일  
> 핵심: 12개 과제 카드를 모아 성과를 정리한 뒤, 우수 과제 2개의 실제 과제명과 담당자를 소개한다.

---

## 1. 제작 목표

12개 개별 과제 영상이 끝난 뒤, 과제별 대표 화면을 카드 형태로 빠르게 모아 하나의 성과 장면으로 정리한다. 이후 “12개의 AI Agent가 만든 변화, 이제 두 개의 우수 과제를 만나봅니다.”라는 메시지를 통해 우수 과제 소개로 자연스럽게 연결한다.

마지막 화면에는 아래 두 과제의 **실제 과제명과 담당자 이름을 반드시 표시**한다. 팀명, `우수과제 01·02` 등의 번호 표기는 넣지 않는다.

- **AI Agent 기반 Plug 대면적 데이터 분석 자동화 및 인사이트 도출** — 김지은 TL
- **RSAB SNM Overlay 열화 원인 분석 및 솔루션 제시 Agent** — 장민희 TL

## 2. 공통 제작 규칙

함께 제공된 `RD_AI_Fast_Track_공통_제작_규칙_타이틀화면추가.md`를 준수한다.

- 16:9 가로형, 권장 해상도 1920 × 1080, 30 fps
- 배경은 검정·차콜, 강조는 골드·앰버
- 기존 오프닝과 서머리의 색상과 시각적 톤을 유지한다.
- 정지 스토리보드 이미지에 자막만 얹는 방식이 아니라, 각 장면의 카드·빛·카메라·텍스트를 실제로 움직인다.
- 화면의 한글 문구는 이미지 생성 결과에 의존하지 말고 편집 가능한 텍스트 레이어로 정확히 구현한다.
- 카드 속 이미지는 같은 이미지를 복제하지 않는다. 각기 다른 과제 유형이 보이도록 공정 장면, 이미지 분석, 데이터 시각화, 장비 화면 등 서로 다른 대표 장면을 사용한다.
- 실제 과제 기능과 관계없는 장면이나 성과 수치는 임의로 추가하지 않는다.

- 각 카드에는 서로 다른 과제의 대표 장면을 배치한다.
- 카드의 예시 이미지: 공정·웨이퍼, 장비 모니터링, 데이터 시각화, 이미지 계측, Overlay 맵 등.
- 카드 이미지가 반복되거나 동일한 웨이퍼 이미지로만 채워지지 않도록 한다.

**모션**
- 카드가 화면 바깥과 깊은 배경에서 촤촤촥 날아와 나타난다.
- 카드마다 미세한 회전과 원근감을 주고, 골드 테두리가 순차적으로 켜진다.
- 카메라는 공간 안쪽으로 짧게 전진한다.

**화면 문구:** 없음

- 12개 카드에는 서로 다른 과제 화면이 유지된다.
- 장식용 숫자나 가상의 성과 지표는 추가하지 않는다.

**모션**

### SCENE 6 — 두 과제명 및 담당자 소개 (10–12초)

**화면 구성**
화면에 두 개의 골드 테두리 카드를 나란히 배치한다. 각 카드에는 실제 과제와 관련된 이미지를 사용하고, **과제명과 담당자 이름을 모두 표시**한다.

**왼쪽 카드 — 김지은 TL**
- 이미지: Plug 대면적 이미지 타일, 계측선, Plug 번호 및 분석 화면
- 과제명: `AI Agent 기반 Plug 대면적 데이터 분석 자동화 및 인사이트 도출`
- 담당자: `김지은 TL`

**오른쪽 카드 — 장민희 TL**
- 이미지: Overlay·Residual·MA Bias Wafer Map, 정상 Baseline과 입력 Wafer 비교 그래프, K-parameter 분석 화면
- 과제명: `RSAB SNM Overlay 열화 원인 분석 및 솔루션 제시 Agent`
- 담당자: `장민희 TL`

**표기 금지**
- `우수과제 01`, `우수과제 02` 표기 금지
- 팀명 표기 금지
- 과제명이나 담당자명을 카드 아래 바깥 영역에 따로 중복 표기하지 않는다.
- 두 카드에 같은 그림을 복제하지 않는다.

**모션**
- 왼쪽과 오른쪽 카드가 서로 다른 방향에서 들어와 나란히 정렬된다.
- 왼쪽 카드에서는 Plug 이미지 타일과 측정 프레임이 짧게 활성화된다.
- 오른쪽 카드에서는 Overlay·Residual·MA Bias 맵이 순서대로 빛나고, K-parameter 패널이 강조된다.
- 과제명과 담당자 이름은 카드 이미지가 자리 잡은 뒤 선명하게 나타난다.
- 마지막 프레임을 짧게 유지한 후 김지은 TL 과제 영상의 시작 타이틀로 전환한다.

**나레이션**
> (나레이션 없음)

**연출 메모**
- 마지막 두 과제 카드는 화면과 배경음악으로만 소개한다.
- 과제명과 담당자명이 충분히 읽히도록 화면을 유지하고, 나레이션은 넣지 않는다.

**중요**
- 이 장면의 카드가 우수 과제 소개를 겸한다. 별도의 `우수과제 01·02` 라벨이나 카드 아래 추가 문구를 넣지 않는다.
- 과제명은 줄바꿈을 허용하되, 단어를 생략하거나 임의로 줄여 쓰지 않는다.
- 2초 안에 모든 텍스트를 읽기 어렵다면 전체 엔딩 길이를 2–3초 연장한다. 과제명을 작게 줄여 가독성을 희생하지 않는다.

**녹음·편집 지침**
