# 오프닝 v2 오디오 소스 및 검증

사용자가 요청한 R&D 발음 수정본입니다. 기존 `opening/` 및 `out/opening/`의 v1 파일은 보존했습니다.

## 재실행

Python 3.9 이상과 `ffmpeg`가 PATH에 설치되어 있어야 합니다. 추가 Python 패키지나 API 키는 필요하지 않습니다.

프로젝트 루트에서 실행합니다.

```sh
python3 opening-v2/audio.py
```

`opening-v2/`만 별도로 옮긴 경우 해당 폴더에서 실행합니다.

```sh
python3 audio.py --output ./output
```

출력은 `audio.wav`, `narration.wav`, `narration-raw.wav`, `audio-validation.json`입니다. HTML 미리보기용 `narration/mix.wav`도 같은 최종 PCM으로 갱신됩니다. 이 스크립트는 원격 음성을 생성하거나 다른 서비스로 음원을 전송하지 않습니다.

저장된 로컬 Whisper 전사와 파형 경계 자료를 이용해 원본 PCM 컷 및 provenance를 다시 검증하려면 다음 명령을 실행합니다.

```sh
python3 opening-v2/narration/align.py
```

## 발화와 화면 문구

`ko.json`의 `text`에는 승인된 화면 자막 원문을 그대로 보존했습니다. `spoken_text`에는 R&D 3곳만 **알앤디**로 바꾸었습니다. 다른 승인 문구는 수정하지 않았습니다. `pronunciation_map`은 `{"R&D":"알앤디"}`이며, `generated_prompt`에는 delivery tag를 한 번만 넣고 9개 `spoken_text`를 이어 붙였습니다.

## 발음 및 문장 검증

기본 로컬 OpenAI Whisper `small` 전사는 R&D 3곳을 영문 약어로 정규화합니다. 따라서 이 표기만으로 발음이 바뀌었다고 판단하지 않았습니다.

추가 전사에서는 단어 힌트를 주지 않고 라틴 R/D/앰퍼샌드 표기 토큰만 제외했습니다. 새 음원의 3곳 모두 **아랜디**로 인식되었습니다. 이는 **알앤디**의 ㄹ 연음 발음을 음절대로 적은 형태입니다. 동일 조건의 v1 참고 전사는 세 곳 모두 `RMDD`였습니다. 원문 입력의 3개 **알앤디**와 이 음성 전사 결과를 함께 기록했습니다. 이 검증은 표기 제약을 공개한 ASR 근거이며, 사람의 청취나 완벽한 글자 단위 전사라고 주장하지 않습니다.

`transcription/korean-orthography/`에 한글 음성 표기 전사, `v1-reference-orthography/`에 이전 음원 비교 전사가 있습니다. 1초 미만 발음 조각만 따로 전사한 실험은 오인식·환각을 반환하여 검증 근거로 사용하지 않았습니다. 해당 결과도 `pronunciation/`에 보존했습니다.

기본 전체 테이크 전사로 9개 문장과 마지막 문장을 확인했습니다. 8개 경계는 단어·문장 타임스탬프와 파형 휴지 구간으로 검증했습니다. 6–7번 사이에는 Whisper가 다음 첫 단어 시작을 앞 문장 끝에 붙였으므로, 정확한 컷 샘플에서 시작하는 별도 원본 구간을 다시 전사해 7번 문장 전체와 첫 단어 보존을 확인했습니다. 기본 전사에는 ‘현업의/현업에’ 등 철자 오차가 남아 있습니다.

## BGM 및 믹스

BGM은 v1과 같은 Andrew Ev의 **Mountains** 도입 0–46초 구간입니다. `bgm/music.mp3`, `bgm/provenance.json`, `bgm/license.html`에 사용 리소스와 당시 확보한 라이선스 문서가 있습니다. 낮은 볼륨, 나레이션에 반응하는 ducking, 부드러운 입·출력 페이드도 유지했습니다.

출처: https://mixkit.co/free-stock-music/tag/corporate/?page=2

라이선스: https://mixkit.co/license/modal/musicFree/

라이선스는 나레이션을 포함한 영상 결합 사용을 위한 것입니다. 음원 단독 재배포·소유권 주장·권리 관리 서비스 등록은 허용되지 않습니다.

최종 믹스는 정확히 **46.000초, 48000 Hz stereo PCM16**, 통합 음량 **−17.13 LUFS**, true peak **−4.91 dBTP**이며 FFmpeg 전체 디코딩을 통과했습니다. 최종 MP4의 AAC·영상 스트림 복사·재생 검수는 별도 영상 검증 보고서에서 확인합니다.
