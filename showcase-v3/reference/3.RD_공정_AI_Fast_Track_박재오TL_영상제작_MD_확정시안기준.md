# R&D 공정 AI Fast Track — 박재오 TL 과제 영상 제작 MD

> **기준 시안:** 사용자가 확정한 5컷 스토리보드 이미지(「R&D 공정 Eng’r 연구 환경 Infra 구축」). 이 MD는 해당 시안의 디자인·화면 구성·장면 순서를 유지하면서, 각 컷의 모션과 전환을 영상 제작자가 구현할 수 있도록 상세화한 지시서다.
> **중요:** 시안 이미지를 한 장 그대로 영상으로 사용하지 않는다. 시안의 5개 패널을 각각 분리된 장면으로 재구성하고, 영상에서는 시간 순서대로 보여준다.

## 1. 과제 정보
- 과제명: R&D 공정 Eng'r 연구 환경 Infra 구축
- 소속/담당: NAND Cell Lab / 박재오 TL
- 핵심 메시지: Lot 이력, Lot Inline, 장비 이력, 장비 FDC, 연계 공정 이력을 하나의 앱에서 조회·분석
- 성과: 발표 자료 기준 Lot 1건 분석 시간 약 2시간 40분 → 20분 이내
- 목표 영상 길이: 약 20~22초
- 화면 비율: 16:9
- 해상도: 1920×1080 Full HD
- 프레임 레이트: 30fps
- 출력: H.264/AAC MP4

## 2. 디자인 — 확정 시안 그대로 유지
- 확정 시안의 레이아웃 언어, 딥블랙 배경, 골드·앰버 조명, 얇은 골드 구분선, 흰색/크림색 타이포그래피를 유지한다.
- 기존 공통 제작 규칙의 색상 팔레트를 따른다: 배경 `#080808`, 딥 차콜 `#1A1A1F`, 골드 `#D4AF7C`, 라이트 골드 `#F5D6A6`, 앰버 `#FFB347`, 보조 텍스트 `#F2EEE7`.
- 파란색/네온 블루가 주조색이 되지 않게 한다. 차트에 필요한 보조 색상은 제한적으로만 쓴다.
- 반도체 웨이퍼, 연구용 모니터, 어두운 연구 환경과 골드 빛의 흐름을 사용한다.
- 확정 시안의 5개 장면 제목과 화면 문구는 임의로 바꾸지 않는다.
- 전체 스토리보드의 상단 정보 영역은 영상 내내 표시하지 않는다. 해당 과제의 제목/담당자는 영상 시작 시 짧은 타이틀로 보여준 뒤 장면 1로 진입해도 된다. 본문은 각 장면을 화면 전체로 보여준다.
- 시안의 차트·대시보드는 시각 연출 예시다. 실제 자료에 없는 세부 분석 기능을 사실처럼 추가하지 않는다.

골드 세로선과 은은한 빛의 이동을 사용한다. 과도한 로고 애니메이션이나 긴 타이틀 화면은 만들지 않는다.

## 4. 나레이션 — 장면 간 이어 읽기
장면별로 문장을 딱딱 끊지 않는다. CUT 1의 미완성 구절이 CUT 2로 이어지고, 뒤의 문장도 흐름을 유지한다. 나레이션은 장면 전환을 가로질러 자연스럽게 이어지도록 편집한다.

### 확정 나레이션 전체본
“흩어져 있는 Lot과 장비, 공정 이력을 하나의 앱에서 한 번에 확인하고, 데이터 간 연계를 통해 종합적으로 분석합니다. 이를 바탕으로 분석 결과를 직관적으로 확인하고, Lot 1건 분석 시간을 약 2시간 40분에서 20분 이내로 줄입니다.”

## 5. 장면별 화면·모션 지시

### CUT 1 — 기존 업무의 어려움 / 흩어진 이력 데이터 (0~4초)
**화면**
- 확정 시안의 첫 번째 패널을 기준으로 구성한다.
- 딥블랙 연구 환경에 모니터와 정보 패널이 여러 곳에 흩어져 있다.
- 화면 레이블은 `Lot 이력`, `Lot Inline`, `장비 이력`, `장비 FDC`, `연계 공정 이력`으로 표시한다.
- 화면 상단 제목: `기존 업무의 어려움`

**나레이션**
“흩어져 있는 Lot과 장비, 공정 이력을…”

**모션을 반드시 구현**
1. 화면은 거의 검은 상태에서 시작하고, 왼쪽 먼 곳의 모니터가 먼저 은은하게 켜진다.
2. `Lot 이력` 패널이 왼쪽에서 짧게 이동하며 나타난다.
3. `Lot Inline`, `장비 이력`, `장비 FDC`, `연계 공정 이력` 패널이 서로 다른 깊이와 위치에서 약 0.3초 간격으로 차례로 등장한다.
4. 각 패널은 2~3도 정도의 미세한 원근 기울기를 갖고, 카메라가 좌우로 천천히 움직이며 여러 화면을 각각 확인하는 상황을 보여준다.
5. 패널의 그래프에는 아주 작은 움직임만 준다. 텍스트가 읽히지 않는 가짜 상세 데이터는 넣지 않는다.
6. CUT 종료 시 다섯 패널이 모두 보이지만, 서로 떨어져 있고 연결되지 않은 상태로 남는다.

**전환**
- 화면 오른쪽 가장자리에서 얇은 골드 라인이 켜지며 다음 컷으로 이어진다.

### CUT 2 — 하나의 앱에서 통합 조회 (4~8초)
**화면**
- 확정 시안의 두 번째 패널을 기준으로 한다.
- 중앙에 하나의 어두운 앱 패널이 나타나고, 이력 메뉴가 세로로 정렬된다.
- 제목: `하나의 앱에서 통합 조회`
- 메뉴: `Lot 이력`, `Lot Inline`, `장비 이력`, `장비 FDC`, `연계 공정 이력`

**나레이션**
“…하나의 앱에서 한 번에 확인하고,”

**모션을 반드시 구현**
1. CUT 1의 분산된 패널에서 얇은 골드 라인이 뻗어 나와 중앙 앱 패널로 흐른다.
2. 앱 패널이 배경 깊은 곳에서 앞으로 천천히 이동하며 크기가 커지고, 화면 중앙에서 정면으로 정렬된다.
3. 다섯 메뉴가 위에서 아래로 0.15~0.25초 간격으로 순차적으로 나타난다.
4. 각 메뉴는 나타날 때 골드 테두리가 짧게 켜졌다가 안정된 상태로 돌아온다.
5. 검색창의 커서 또는 검색 아이콘이 한 번 움직여 조회 동작을 암시한다. 실제 검색 결과나 구체적인 Lot ID는 임의로 만들지 않는다.
6. 카메라는 앱 화면을 향해 천천히 푸시인(push-in)한다.

**전환**
- 앱 안의 각 메뉴에서 골드 연결선이 뻗어 나와 CUT 3의 데이터 연계 화면으로 이어진다.

### CUT 3 — 데이터 연계 분석 (8~12초)
**화면**
- 확정 시안의 세 번째 패널을 기준으로 한다.
- `공정 이력`, `장비 데이터`, `Lot 데이터`, `FDC 데이터`, `연계 공정`을 상징하는 데이터 패널이 보인다.
- 각 패널은 중앙의 연결 지점을 중심으로 연결된다.
- 제목: `데이터 연계 분석`

**나레이션**
“데이터 간 연계를 통해 종합적으로 분석합니다.”

**모션을 반드시 구현**
1. 각 데이터 패널이 서로 다른 높이에서 차례로 나타난다.
2. 패널 사이를 연결하는 골드 라인이 한 줄씩 순차적으로 그려진다.
3. 작은 빛 입자가 라인을 따라 이동해 데이터가 연결되는 흐름을 보여준다.
4. 중앙 연결 지점에서 은은한 빛이 한 번 퍼지고, 패널들이 약간 안쪽으로 정렬된다.
5. 일반적인 차트 선이 왼쪽에서 오른쪽으로 그려지며 분석이 진행되는 느낌을 준다.
6. 카메라는 패널 전체에서 중앙 연결 지점으로 천천히 이동한 뒤 결과 화면으로 부드럽게 넘어간다.

**주의**
- 실제 자료에서 확인되지 않은 `이상 패턴 탐지`, `원인 후보`, 특정 공정 영향도 등은 실제 기능으로 표시하지 않는다.
- 세부 데이터 값과 범례를 임의로 생성하지 않는다.

**전환**
- 연결된 선이 화면 오른쪽으로 흐르며 CUT 4의 대시보드 화면으로 이어진다.

### CUT 4 — 분석 결과 시각화 (12~16초)
**화면**
- 확정 시안의 네 번째 패널을 기준으로 한다.
- 어두운 통합 대시보드에 일반적인 그래프와 표가 배치된다.
- 제목: `분석 결과 시각화`
- 실제 과제 화면이 별도로 제공되면 실제 화면을 우선한다. 없으면 추상적인 그래프/표를 사용하고 검증되지 않은 결과를 텍스트로 단정하지 않는다.

**나레이션**
“이를 바탕으로 분석 결과를 직관적으로 확인하고,”

**모션을 반드시 구현**
1. 대시보드가 화면 왼쪽에서 부드럽게 슬라이드 인한 뒤 정면으로 정렬된다.
2. 그래프 선이 왼쪽에서 오른쪽으로 그려지고, 데이터 포인트가 순차적으로 나타난다.
3. 표는 위에서 아래로 행이 차례로 나타나며, 선택 영역 하나에만 얇은 골드 강조 테두리가 켜진다.
4. 카메라가 대시보드 전체에서 그래프, 표로 부드럽게 이동해 결과를 확인하는 느낌을 준다.
5. 마지막 0.5초에는 화면이 살짝 어두워지고, 오른쪽에 성과 수치가 들어올 공간을 만든다.

**전환**
- 대시보드의 골드 테두리가 화면을 가로지르는 빛으로 변하며 CUT 5로 이어진다.

### CUT 5 — 분석 시간 단축 (16~22초)
**화면**
- 확정 시안의 다섯 번째 패널을 기준으로 한다.
- 딥블랙 배경에 기존 시간과 개선 후 시간을 나란히 표시한다.
- 제목: `분석 시간 단축`
- `기존 약 2시간 40분`
- `개선 후 20분 이내`
- 보조 문구: `Lot 1건 분석 시간`

**나레이션**
“Lot 1건 분석 시간을 약 2시간 40분에서 20분 이내로 줄입니다.”

**모션을 반드시 구현**
1. `기존 약 2시간 40분`이 화면 왼쪽에서 짧게 페이드 인한다.
2. 옆의 시계 아이콘이 천천히 회전한다.
3. 골드 빛의 화살표가 왼쪽에서 오른쪽으로 이동한다.
4. `20분 이내`가 오른쪽에서 약간 작게 시작해 부드럽게 확대되며 등장한다.
5. 숫자가 등장하는 순간 `20분 이내`에 골드 글로우를 짧게 적용하고, 이후 안정적으로 유지한다.
6. 배경의 웨이퍼는 천천히 회전하거나 카메라가 미세하게 앞으로 이동한다. 성과 숫자보다 시각 효과가 튀지 않게 한다.
7. 마지막 0.8~1초는 성과 수치를 읽을 수 있도록 안정된 상태로 유지한다.

**마무리**
- 골드 라인이 화면을 가로질러 다음 과제 영상으로 연결된다.
- 추가 슬로건이나 확인되지 않은 효과를 덧붙이지 않는다.

## 6. 음향 지시
- 배경음악: 차분하고 고급스러운 시네마틱 전자음악. 딥블랙·골드 비주얼에 어울리는 절제된 분위기.
- CUT 1: 패널 등장마다 낮고 부드러운 UI 사운드를 아주 작게 사용.
- CUT 2: 골드 연결선이 앱으로 모일 때 부드러운 흡입/연결 사운드.

## 8. 필수 구현 및 금지 사항
### 필수 구현
- 5개 컷이 각각 움직이는 실제 영상 장면으로 보여야 한다.
- 데이터 패널 등장/이동, 앱 패널 확대·정렬, 연결선 흐름, 그래프 애니메이션, 카메라 이동, 성과 숫자 전환을 구현한다.
- 나레이션은 장면 경계에서 끊기지 않고 자연스럽게 이어진다.
- 텍스트는 코드 또는 편집 도구로 정확하게 렌더링한다.
- 모든 움직임은 부드럽고 절제된 속도로 구현한다.

### 금지
- 확정 시안과 무관한 새 디자인으로 변경하기
- 스토리보드 이미지 한 장을 정지 화면으로 띄워놓기
- 자막만 바꾸고 화면은 움직이지 않는 영상
- 파란색/네온 블루를 메인 컬러로 사용하기
- 실제 자료에 없는 기능, 결과, 경고, 수치, 원인 분석을 추가하기
- 한글 텍스트를 이미지 생성 결과에 맡겨 오탈자가 생기게 하기
