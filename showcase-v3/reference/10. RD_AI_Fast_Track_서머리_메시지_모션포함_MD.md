# 반복 업무를 줄이고, 분석에 집중하다
## 서머리 메시지 영상 제작 MD

> 목적: 확정된 단일 장면 시안을 기준으로 약 6–8초 길이의 시네마틱 모션 영상을 제작한다.  
> 중요: 화면에 `SUMMARY 1`, `SUMMARY 2`, `SUMMARY 3` 등 서머리 번호나 라벨을 표시하지 않는다.

---

## 1. 영상 콘셉트

**핵심 메시지**
- 메인 문구: `반복 업무를 줄이고`
- 메인 문구 2행: `분석에 집중하다`
- 보조 문구: `데이터 분석과 반복 업무 자동화로`
- 보조 문구 2행: `더 효율적인 R&D 환경을 만듭니다.`

네 과제의 공통점을 종합해, 데이터 분석과 반복 업무 자동화가 R&D 업무 효율 향상으로 이어진다는 메시지를 전달한다. 개별 과제명을 나열하거나 네 과제의 기능을 하나의 공통 기능처럼 묘사하지 않는다.

## 2. 공통 디자인 규칙

- 화면 비율: 16:9 가로형
- 권장 해상도: 1920 × 1080
- 권장 프레임레이트: 30 fps
- 시각 스타일: 검정·차콜 배경, 골드·앰버 포인트, 프리미엄 반도체 R&D 분위기
- 기본 색상:
  - Black: `#080808`
  - Charcoal: `#1A1A1F`
  - Gold: `#D4AF7C`
  - Light Gold: `#F5D6A6`
  - Amber: `#FFB347`
  - Cream: `#F2EEE7`
- 시안의 중심 웨이퍼, 주변 데이터 패널, 골드 빛의 흐름, 중앙 문구 구도를 유지한다.
- `SUMMARY 1`, `SUMMARY 2`, `SUMMARY 3`, `SUMMARY 4`, `SUMMARY 3` 같은 번호나 영문 라벨을 추가하지 않는다.
- 과제명이나 담당자명을 넣지 않는다. 이 영상은 개별 과제 타이틀이 아니라 서머리의 종합 메시지 장면이다.
- 문구는 정확한 한국어로 별도 텍스트 레이어로 구현한다. 이미지 안의 글자를 그대로 사용해야 하는 방식은 피하고, 오탈자 없는 텍스트를 영상 편집 단계에서 올린다.
- 불필요한 새 UI, 수치, 과제별 세부 기능을 임의로 추가하지 않는다.

## 3. 길이 및 타임라인

총 길이: 약 6–8초. 한 장면을 유지하되, 조명·카메라·UI·텍스트에 움직임을 적용한다.

### 0.0–1.5초 — 어둠에서 웨이퍼가 드러남
- 시작은 거의 검정에 가까운 화면.
- 웨이퍼 아래의 골드 링 조명이 순차적으로 켜진다.
- 웨이퍼 표면을 따라 미세한 빛이 이동하고, 주변 패널이 어둠 속에서 서서히 드러난다.
- 카메라는 낮은 위치에서 웨이퍼를 향해 천천히 전진한다.
- 텍스트는 아직 모두 표시하지 않는다.

### 1.5–3.0초 — 데이터 흐름 활성화
- 좌우의 데이터 패널이 서로 다른 깊이에서 미세하게 떠오르거나 움직인다.
- 골드 데이터 스트림이 주변 패널에서 중앙과 웨이퍼 방향으로 흐른다.
- 패널은 크게 회전하거나 화면을 가리지 않도록 하고, 작은 패럴랙스와 밝기 변화로 깊이감을 준다.
- 웨이퍼는 실제로 회전시키기보다 표면의 빛과 반사광이 이동하는 방식으로 고급스럽게 표현한다.

### 3.0–4.5초 — 메인 문구 등장
- 메인 문구를 두 단계로 표시한다.
  1. `반복 업무를 줄이고`
  2. `분석에 집중하다`
- 첫 번째 줄이 짧게 페이드·이동하며 등장하고, 두 번째 줄은 골드 포인트와 함께 이어서 나타난다.
- `분석에 집중하다`의 골드 강조는 시안의 디자인을 유지한다.
- 텍스트가 화면에 튀거나 과도하게 확대되지 않도록 부드러운 모션을 사용한다.
- 텍스트는 중앙에 안정적으로 정렬하고 웨이퍼와 주변 UI를 과도하게 가리지 않는다.

### 4.5–6.5초 — 보조 문구와 빛의 강조
- 보조 문구를 두 줄로 표시한다.
  - `데이터 분석과 반복 업무 자동화로`
  - `더 효율적인 R&D 환경을 만듭니다.`
- 중앙 웨이퍼의 골드 조명이 가장 밝아지며, 골드 라인이 웨이퍼 가장자리를 따라 한 번 흐른다.
- 주변 패널은 낮은 강도의 움직임을 유지하되 메인 문구보다 눈에 띄지 않게 한다.
- 카메라는 아주 천천히 전진해 화면에 깊이감을 더한다.

### 6.5–8.0초 — 메시지 유지 및 다음 영상 연결
- 모든 문구를 읽을 수 있도록 짧게 유지한다.
- 배경 움직임은 부드럽게 이어진다.
- 마지막에 완전히 멈춘 정지 화면처럼 보이지 않도록 빛과 미세한 패럴랙스를 유지한다.
- 다음 영상으로 연결할 경우 골드 빛이 화면 가장자리로 흐르며 자연스럽게 전환한다. 별도 서머리 번호나 엔딩 크레딧을 추가하지 않는다.

## 4. 모션 구현 지침

이 영상은 한 장의 이미지에 단순 확대 효과만 적용하는 방식이 아니다. 아래 요소를 실제로 움직이게 구현한다.

- **카메라:** 느린 푸시인과 미세한 시차 이동
- **웨이퍼:** 표면 반사광과 링 조명의 흐름, 미세한 빛의 이동
- **데이터 패널:** 깊이별 미세한 패럴랙스, 약한 밝기 변화, 제한적인 부유 움직임
- **데이터 스트림:** 골드 입자와 빛의 흐름이 주변 패널과 웨이퍼 방향으로 이동
- **텍스트:** 메인 문구와 보조 문구를 시간차를 두고 등장
- **조명:** 시작은 어둡게, 중간에는 데이터 흐름을 활성화, 메인 문구 등장 시 웨이퍼와 골드 포인트를 강조

움직임은 고급스럽고 절제된 수준으로 유지한다. 빠른 회전, 강한 흔들림, 과도한 글로우, 폭발적인 전환은 사용하지 않는다.

## 5. 사운드

- 배경음악: 짧고 세련된 시네마틱 전자음. 웅장함을 과도하게 강조하지 않는다.
- 시작: 낮은 저음과 함께 골드 링 조명이 켜지는 소리.
- 데이터 흐름: 아주 낮은 전자적 상승음.
- 메인 문구 등장: 부드러운 임팩트 사운드.
- 보조 문구 등장: 잔잔한 고음 또는 짧은 공명.
- 종료: 다음 영상과 이어질 수 있도록 음악을 완전히 끊지 않고 짧게 정리한다.
- 별도 나레이션은 추가하지 않는다. 화면 문구와 배경음악만 사용한다.

## 6. 정확성 및 금지사항

- 화면에 서머리 번호나 `SUMMARY` 문구를 표시하지 않는다.
- 화면 문구는 아래 문구만 사용한다.
  - `반복 업무를 줄이고`
  - `분석에 집중하다`
  - `데이터 분석과 반복 업무 자동화로`
  - `더 효율적인 R&D 환경을 만듭니다.`
- 문구를 임의로 바꾸거나 추가 설명을 넣지 않는다.
- 특정 과제에만 해당하는 기능이 모든 과제의 공통 기능처럼 보이도록 묘사하지 않는다.
- 수치 성과, 과제명, 담당자명, 불필요한 크레딧은 넣지 않는다.
- 확정 시안의 검정·골드 색상, 웨이퍼 중심 구도, 주변 데이터 패널을 유지한다.
- 정지 이미지 슬라이드쇼가 아닌 실제 모션을 구현한다.
