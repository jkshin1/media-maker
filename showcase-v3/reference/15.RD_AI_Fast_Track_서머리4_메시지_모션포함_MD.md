# 이미지와 데이터를 분석해, 더 정교한 연구를 실현하다
## 서머리 메시지 영상 제작 MD

> 제작 기준: 사용자가 확정한 단일 메시지 장면 시안  
> 목적: 김성후 TL의 TCAD-TEM 이미지 라벨링 과제와 김지은 TL의 AI Agent 기반 Plug 대면적 데이터 분석 과제를 종합하는 메시지 영상  
> 중요: 화면에 `SUMMARY 1`, `SUMMARY 2`, `SUMMARY 3`, `SUMMARY 4` 등 서머리 번호나 라벨을 표시하지 않는다.

---

## 1. 영상 콘셉트

**메인 문구**
- 1행: `이미지와 데이터를 분석해`
- 2행: `더 정교한 연구를 실현하다`

**보조 문구**
- 1행: `이미지 측정과 대규모 데이터 분석을 효율화해`
- 2행: `더 신뢰도 높은 연구 결과를 지원합니다.`

이 장면은 이미지 라벨링·측정과 대규모 Plug 데이터 분석이라는 서로 다른 과제를, 이미지와 데이터 분석을 통한 연구 효율 및 결과 신뢰도 향상이라는 공통 메시지로 묶는다. 정확도만 강조하지 않고, 반복적인 측정 업무의 효율화와 대규모 데이터 분석도 함께 표현한다.

## 2. 공통 디자인 규칙

- 화면 비율: 16:9 가로형
- 권장 해상도: 1920 × 1080
- 권장 프레임레이트: 30 fps
- 시각 스타일: 검정·차콜 배경, 골드·앰버 포인트, 프리미엄 반도체 R&D 분위기
- 기본 색상:
  - Black: `#080808`
  - Charcoal: `#1A1A1F`
  - Gold: `#D4AF7C`
  - Light Gold: `#F5D6A6`
  - Amber: `#FFB347`
  - Cream: `#F2EEE7`
- 확정 시안의 중앙 웨이퍼, 좌우 분석 패널, 중앙 문구, 골드 데이터 스트림 구도를 유지한다.
- `SUMMARY 1`, `SUMMARY 2`, `SUMMARY 3`, `SUMMARY 4` 등의 번호·영문 라벨을 추가하지 않는다.
- 과제명, 담당자명, 과제 번호를 넣지 않는다. 이 영상은 개별 과제 소개가 아니라 서머리의 종합 메시지 장면이다.
- 한국어 문구는 이미지에 생성된 글자를 그대로 사용하지 말고, 편집 단계에서 정확한 텍스트 레이어로 삽입한다.
- 실제 기능으로 확인되지 않은 수치나 기능을 새로 추가하지 않는다.

## 3. 길이 및 타임라인

총 길이: 약 6–8초. 단일 장면을 유지하되 카메라·조명·분석 패널·이미지 카드·텍스트가 실제로 움직이도록 제작한다.

### 0.0–1.5초 — 이미지와 분석 패널 등장
- 어두운 반도체 R&D 공간에서 시작한다.
- 좌우 패널의 현미경 이미지, 측정 화면, 대규모 이미지 목록, 분석 그래프가 순차적으로 드러난다.
- 패널은 서로 다른 깊이에 배치해 입체감을 형성한다.
- 카메라는 중앙 웨이퍼를 향해 천천히 전진한다.
- 메인 문구는 아직 완전히 표시하지 않는다.

### 1.5–3.0초 — 이미지와 데이터 연결
- 좌우 패널에서 중앙 웨이퍼 방향으로 골드 데이터 스트림이 흐른다.
- 일부 이미지 카드가 공간에서 천천히 이동하며 중앙으로 연결된다.
- 왼쪽 패널은 이미지 측정·라벨링, 오른쪽 패널은 대규모 데이터 분석·오측 탐지·분석 결과를 상징한다.
- 한 과제의 기능이 다른 과제에도 모두 적용되는 것처럼 보이지 않도록 패널별 기능을 시각적으로 구분한다.

### 3.0–4.5초 — 메인 문구 등장
- 중앙 문구를 두 단계로 표시한다.
  1. `이미지와 데이터를 분석해`
  2. `더 정교한 연구를 실현하다`
- 첫 번째 줄이 부드럽게 나타난 뒤, 두 번째 줄이 골드 강조와 함께 이어서 등장한다.
- 중앙 정렬을 유지하고 좌우 분석 패널과 웨이퍼를 과도하게 가리지 않는다.

### 4.5–6.5초 — 보조 문구와 분석 패널 강조
- 보조 문구를 두 줄로 순차적으로 표시한다.
  - `이미지 측정과 대규모 데이터 분석을 효율화해`
  - `더 신뢰도 높은 연구 결과를 지원합니다.`
- 좌측 이미지 측정 패널과 우측 대규모 데이터 분석 패널의 골드 테두리가 차례로 강조된다.
- 웨이퍼 표면의 반사광과 골드 링 조명이 한 차례 흐르듯 이동한다.
- 카메라는 아주 천천히 전진해 화면에 깊이감을 더한다.

### 6.5–8.0초 — 메시지 유지 및 자연스러운 전환
- 모든 문구를 읽을 수 있도록 짧게 유지한다.
- 분석 패널, 이미지 카드, 데이터 스트림과 조명은 미세하게 계속 움직인다.
- 다음 영상으로 연결할 경우 골드 데이터 스트림이 화면 가장자리로 흐르며 자연스럽게 전환한다.
- 별도 엔딩 크레딧이나 서머리 번호를 추가하지 않는다.

## 4. 모션 구현 지침

단순히 확정 시안 이미지를 확대하거나 축소하는 방식으로 제작하지 않는다. 다음 요소를 실제로 움직이게 구현한다.

- **카메라:** 웨이퍼를 향한 느린 푸시인과 미세한 시차 이동
- **분석 패널:** 서로 다른 깊이에서 미세한 패럴랙스와 제한적인 부유 움직임
- **이미지 카드:** 일부 현미경 이미지 카드가 천천히 이동하며 분석 흐름을 형성
- **측정 UI:** 측정선이나 선택 프레임이 짧게 움직이며 이미지 측정 과정을 상징
- **데이터 스트림:** 좌우 패널을 중앙 웨이퍼와 연결하는 골드 빛과 입자
- **웨이퍼:** 표면 반사광과 링 조명의 흐름, 미세한 빛의 이동
- **텍스트:** 메인 문구와 보조 문구를 시간차를 두고 등장
- **조명:** 시작은 어둡게, 이미지·데이터가 연결될 때 골드 조명을 강화하고 문구 등장 시 중앙의 대비를 높인다.

움직임은 고급스럽고 절제된 수준으로 유지한다. 빠른 회전, 강한 흔들림, 과도한 글로우, 폭발적인 전환은 사용하지 않는다.

## 5. 사운드

- 배경음악: 세련되고 절제된 시네마틱 전자음. 별도 나레이션은 사용하지 않는다.
- 시작: 낮은 저음과 함께 분석 패널이 드러나는 소리.
- 이미지·데이터 연결: 은은한 상승음과 짧은 전자음.
- 메인 문구 등장: 부드러운 임팩트 사운드.
- 보조 문구 등장: 짧은 공명음을 사용한다.
- 종료: 다음 영상과 이어질 수 있도록 음악을 완전히 끊지 않고 짧게 정리한다.

## 6. 정확성 및 금지사항

- 화면에 서머리 번호나 `SUMMARY` 문구를 표시하지 않는다.
- 화면 문구는 아래 문구만 사용한다.
  - `이미지와 데이터를 분석해`
  - `더 정교한 연구를 실현하다`
  - `이미지 측정과 대규모 데이터 분석을 효율화해`
  - `더 신뢰도 높은 연구 결과를 지원합니다.`
- 문구를 임의로 변경하거나 추가 설명을 넣지 않는다.
- 김성후 TL 과제의 이미지 회전·측정·라벨링과 김지은 TL 과제의 대규모 Plug 데이터 분석·오측 탐지 요소를 구분해 표현한다.
- 특정 과제에만 해당하는 기능이 두 과제 모두의 기능처럼 보이도록 표현하지 않는다.
- 성과 수치, 과제명, 담당자명, 불필요한 크레딧을 넣지 않는다.
- 확정 시안의 검정·골드 색상, 웨이퍼 중심 구도, 좌우 분석 패널, 중앙 문구를 유지한다.
- 정지 이미지 슬라이드쇼가 아닌 실제 모션을 구현한다.
